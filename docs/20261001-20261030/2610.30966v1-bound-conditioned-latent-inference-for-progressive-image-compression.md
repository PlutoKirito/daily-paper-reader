## 摘要
渐进式图像压缩从单个码流的前缀重建图像，因此涉及部分观测下的序列潜变量推断。现有的三进制平面编解码器主要将解码出的三进制符号视为用于概率预测的离散符号，而未充分利用其对底层连续潜变量施加区间约束的作用。我们提出边界条件化潜变量推断（BLI），该框架将渐进式三进制平面编码重新表述为收缩区间约束下的序列潜变量推断。在每个编码步骤中，截至目前解码出的三进制符号为每个潜变量元素定义下界和上界。BLI 利用这些边界区间的中心与宽度，以及编码器和解码器共享的超先验信息，联合细化用于熵建模的高斯参数（μ, σ）和用于重建的潜变量估计 ŷ。随着更多三进制符号被解码，可行区间单调收缩，为下一步推断提供更紧的约束，并支持灵活的平面内细化调度。在 Kodak、CLIC 和 JPEG-AI 上的实验表明，BLI 在渐进式图像编解码器中取得了最先进的率失真性能：在 Kodak 上，相较于 DPICT 将 BD-rate 降低 17.78%，相较于 CTC 降低 7.96%；同时，它用一个共享模型替代 CTC 中特定于平面的预测器，该模型参数量约少 5.3 倍，且延迟低于 CTC。

## Abstract
Progressive image compression reconstructs images from prefixes of a single bitstream and therefore involves sequential latent inference under partial observations. Existing trit-plane codecs mainly treat decoded trits as discrete symbols for probability prediction, without fully exploiting their role as interval constraints on the underlying continuous latents. We propose bound-conditioned latent inference (BLI), a framework that reformulates progressive trit-plane coding as sequential latent inference under shrinking interval constraints. At each coding step, the trits decoded so far define lower and upper bounds for each latent element. BLI uses the center and width of these bounds, together with hyperprior information shared by the encoder and decoder, to jointly refine the Gaussian parameters $(μ,σ)$ for entropy modeling and the latent estimate $\hat{y}$ for reconstruction. As additional trits are decoded, the feasible intervals shrink monotonically, yielding tighter constraints for the next inference step and enabling flexible in-plane refinement schedules. Experiments on Kodak, CLIC, and JPEG-AI show that BLI achieves state-of-the-art rate-distortion performance among progressive image codecs, reducing BD-rate by $17.78\%$ over DPICT and by $7.96\%$ over CTC on Kodak, while replacing CTC's plane-specific predictors with a shared model that uses about $5.3\times$ fewer parameters and achieves lower latency than CTC.

## 1. 核心问题与整体含义

- **研究背景**：渐进式图像压缩要求解码器能从**单一码流的前缀**逐步重建图像，适用于自适应流媒体、带宽受限传输、多质量级存储等场景。与固定码率压缩不同，中间解码步骤只收到部分潜变量，未解码部分必须从部分观测中推断。
- **核心问题**：现有基于 trit-plane 的渐进编解码器（DPICT、CTC）主要把已解码 trits 当作**离散符号**用于概率预测和重建更新，未显式利用它们对底层**连续潜变量**施加的**区间约束**。
- **关键观察**：在 trit-plane 编码中，已解码 trits 实际上把每个连续潜变量限制在一个可行区间内，该区间可作为潜变量推断的显式约束。
- **整体含义**：论文把渐进 trit-plane 编码重新表述为**收缩区间约束下的序列潜变量推断**，并据此提出 BLI（Bound-Conditioned Latent Inference）框架。它在每个编码步骤联合细化熵建模的高斯参数与重建潜变量估计，从而提升率失真性能，同时用共享模型替代 CTC 的平面专用预测器。

## 2. 方法论

### 2.1 核心思想

- 将每个部分解码的潜变量元素视为受上下界约束的连续变量；随着更多 trits 解码，可行区间**单调收缩**，为下一步推断提供更紧约束。
- 每一步利用区间**中心 C**、**宽度 D**（及半宽 D/2）与编码器/解码器共享的**超先验参数 (M0, Σ0)**，同时输出：
  - 熵编码用的高斯参数 **(Mk, Σk)**；
  - 重建用的潜变量估计 **Ŷ(k−1)**。
- 与 POCS 等投影可行性方法概念相关，但 BLI 使用**学习到的 amortized 估计器**，直接以熵建模和重建质量为训练目标，而非精确度量投影。

### 2.2 关键技术细节

- **状态定义**：第 k 步维护 (Mk, Σk)、Ŷk、(Lk, Uk) 及中心/宽度：
  - Ck = (Lk + Uk)/2，Dk = Uk − Lk。
  - 初始 (M0, Σ0) 由 hyperprior 熵模型给出，(L0, U0) 定义初始可行支撑。
- **三进制区间划分**：当前区间 I(k−1) 等分为三个子区间，对应下一个 trit；若 yi 落入第 ti 个子区间，编码该 trit 的码长为 −log2 P(yi ∈ I(k−1, ti) | Mk, Σk)。
- **损失函数**：
  - 率损失 LR = −Σ log2 P(·)，失真损失 LD = ‖X − gs(Ŷk)‖²。
  - 总损失按各 trit-plane 端点累加：L = Σ_{l∈Kend} αl ( Σ_{k=1}^{l} LR + λ LD )。
  - αl 按量化区间平方反比设置，从 LST 到 MST 按 (1/9)^0 … (1/9)^4 递减，以平衡不同平面尺度。
- **重建预测**：Ŷ(k−1) = C(k−1) + ΔŶ(k−1)，即预测相对区间中心的残差修正；输出经 tanh 激活并按 D(k−1)/2 在中心附近缩放，保证与可行区间一致。
- **架构**：输入 C(k−1)、D(k−1)/2 与 (M0, Σ0)；10 层 Swin attention（hidden 960、16 heads、window 8）提取边界条件特征，经 CNN 分支（4 层 depthwise conv）与 plane-wise MLP 头分别输出 (Mk, Σk) 与 Ŷ；Mk 与 Ŷ 分支额外拼接 C 与 D/2。
- **编解码流程**：初始化 C0 = M0、D0 = 3^{ni}（ni = ⌈log3(2κΣ0_i)⌉，κ = −Φ⁻¹(5×10⁻¹⁰)）→ BLI 估计 (Mk, Σk, Ŷ) → 用 ANS 熵编码/解码当前步 trits → 更新边界 → 进入下一步。
- **实现**：嵌入 FTIC 骨干，将原 channel-wise 自回归熵模型替换为非自回归 hyperprior 变体，从 hyper latent Z 估计 (M0, Σ0)。

### 2.3 训练与调度

- 两阶段训练：先训练修改后的 FTIC 骨干（1.0M 迭代，lr 1e-4）；再训练 BLI（0.5M 迭代，lr 5e-5，λ = 0.0483）。
- 训练时每个 trit-plane 均分 4 步，Kend = {4, 8, 12, 16, 20}，trits 随机分配到各步以覆盖多样部分观测模式；随后用 R-D 优先顺序微调。
- 评估时采用非均匀调度 Kend = {4, 8, 14, 30, 54}，越接近 LST 分配越多细化步（高熵 trits 更多）。

- **离散 vs 连续建模**：与 IPAR + discrete 的对照表明，连续潜变量 + 区间约束的建模方式优于把已解码 trits 仅作离散符号条件的做法，支持论文的核心论点。
- **测试时消融**：分别关闭熵参数细化 (Mk, Σk) 与重建预测 Ŷ 两条通路，二者各自贡献增益，且联合使用时收益最大，说明“熵建模”与“重建”两个目标共享同一区间条件表征是有效设计而非冗余。

- **定性结果**：在 Kodak/CLIC/JPEG-AI 及 Tecnick 挑战性色彩图案上的可视化显示，BLI 在中间步骤即可恢复结构与色彩，伪影（如色彩偏移、块状模糊）少于对比方法，与其在低码率感知指标上的优势一致。

## 7. 局限性

- **训练/评估调度不一致**：训练采用每平面 4 步的均匀划分与随机 trit 分配，评估采用非均匀调度 (4, 8, 14, 30, 54)；虽然有利于实际性能，但使消融实验与主实验的对比条件不完全一致，读者难以精确分离“调度收益”与“方法收益”。
- **对 trit-plane 框架的依赖**：方法建立在三进制平面编码与等分区间划分之上，区间单调收缩的性质是推断的前提；推广到二进制/多进制或非等分量化时需重新设计区间更新规则。
- **高斯支撑截断的近似**：初始区间由 κ = −Φ⁻¹(5×10⁻⁴·¹⁰?) 之类的极端分位数确定，实际是对高斯尾部的截断近似，理论上存在极小概率的越界情形，论文未讨论其处理方式与影响。
- **延迟结构性问题**：虽然总时延低于对比方法，但神经推理时间反而更高（3.72s），优势主要来自非神经处理开销的下降；解码仍是逐步串行的，步数增加会线性放大推理开销，实时高帧率场景仍受限。
- **评价范围**：以 PSNR/MS-SSIM 为主，感知指标仅在三个低码率点报告；未覆盖极低码率（<0.05 bpp）、高分辨率 4K、屏幕内容/合成图像等分布外场景；PLONQ 在 CLIC 上结果缺失，跨方法比较的完整性略有欠缺。

## 8. 启发与可借鉴点

- **把“已解码信息”当作约束而非条件**：将部分观测解释为对连续隐变量的可行域收缩，是一个可迁移的建模视角，可推广到渐进式视频编码、分层神经场传输、渐进式 3D 表示等“前缀可解码”问题。
- **共享 amortized 估计器替代平面专用模块**：用单一网络以 (C, D/2, M0, Σ0) 为条件统一处理所有平面，既压缩参数量又提升性能，是“条件化替代专用化”的典型案例。
- **解析区间积分替代离散概率枚举**：用高斯 CDF 直接计算 trit 落入子区间的概率，避免了对子区间内离散符号的循环累加，是其非神经开销大幅下降的关键工程技巧。
- **输出锚定在可行域内**：以 C + tanh(·)·D/2 的参数化保证重建值始终落在收缩区间内，是一种简单有效的“结构约束嵌入网络输出”的做法。
- **训练时随机化部分观测模式**：随机分配 trits 到各步，使单一模型覆盖多种前缀长度，避免了为每个码率点单独训练的代价，对渐进式/可分级系统的训练调度设计有参考价值。

## 9. 一句话总结

论文将渐进 trit-plane 解码重新表述为“收缩区间约束下的序列潜变量推断”，用共享的 amortized 网络联合细化熵参数与重建估计，在显著更小参数量与更低总时延下取得渐进式图像压缩的 SOTA 率失真与感知性能，方法视角清晰、消融较完整，但在调度一致性、延迟结构与分布外场景上仍有进一步验证空间。

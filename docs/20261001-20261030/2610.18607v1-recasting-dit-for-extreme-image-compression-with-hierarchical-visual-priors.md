## 摘要
预训练扩散模型为极端图像压缩提供了强大的生成先验，但其随机、迭代的生成过程并非为直接解码压缩表示而设计。我们提出PrismCodec，将预训练的扩散Transformer（DiT）重构为基于比特流的一步生成式解码器。PrismCodec以两种互补方式使用解码表示：投影后的编解码器状态定义生成的起始状态，而由同一解码潜在表示得到的分层视觉先验提供语义和结构引导。为弥合随机迭代生成与确定性一步解码之间的差距，我们提出一种渐进式适配策略。我们首先从以编解码器状态为中心的噪声邻域中学习以编解码器为条件的传输，将其蒸馏为一步映射，最后在端到端优化过程中将源扰动退火至零。所得解码器从接收到的表示进行确定性重建，无需额外条件比特。在Kodak、CLIC和DIV2K上，PrismCodec相比先前生成式编解码器持续提升率-感知性能，在StableCodec上实现LPIPS的BD-rate降低70-75%和DISTS的BD-rate降低75-81%。代码将在论文接收后发布。

## Abstract
Pretrained diffusion models provide powerful generative priors for extreme image compression, but their stochastic, iterative generation processes are not designed to decode compressed representations directly. We present PrismCodec, which recasts a pretrained Diffusion Transformer (DiT) as a bitstream-grounded one-step generative decoder. PrismCodec uses the decoded representation in two complementary roles: a projected codec state defines the starting state for generation, while hierarchical visual priors derived from the same decoded latent provide semantic and structural guidance. To bridge the gap between stochastic, iterative generation and deterministic one-step decoding, we develop a progressive adaptation strategy. We first learn codec-conditioned transport from a noisy neighborhood centered on the codec state, distill it into a one-step mapping, and finally anneal the source perturbation to zero during end-to-end optimization. The resulting decoder reconstructs deterministically from the received representation without additional conditioning bits. Across Kodak, CLIC, and DIV2K, PrismCodec consistently improves rate-perception performance over prior generative codecs, achieving BD-rate reductions of 70-75% in LPIPS and 75-81% in DISTS over StableCodec. Code will be released upon acceptance.

## 一、核心问题与研究背景

- **背景**：在极端低码率（约 0.01–0.06 bpp）下，基于优化变换与熵模型的学习编解码器只能保留极有限的视觉证据，因此生成式压缩必须借助图像生成先验来"合成"未传输的细节。
- **核心矛盾**：压缩不同于无约束生成——"看起来合理"并不够，重建必须与比特流中保留的证据一致。而预训练扩散/流模型是**随机、迭代**生成的，与压缩解码所需的**确定性、一步**解码在机制上并不对齐。
- **现有工作的接口差异**：OneDC、DiT-IC 从压缩表示派生语义引导；AEIC 移除文本条件；NeFIC、StableCodec 保留固定文本条件但通过解码锚或编解码潜变量注入图像相关信息。这些工作说明"证据如何暴露给生成器"是关键。
- **论文提出的两个未解问题**：
  1. 传输证据应如何同时决定**生成起始状态**与**视觉引导**？
  2. 为随机迭代生成而建的预训练模型，如何被适配为**确定性一步解码**？
- **整体含义**：论文主张把"编解码状态"与"视觉先验"作为两种互补角色分开处理，并通过渐进式适配完成从随机生成到确定性解码的转变，且**不引入任何额外条件比特**。

## 二、方法论

### 2.1 核心思想

将预训练 DiT 重铸为**比特流驱动的一步生成解码器**。解码表示承担两个互补角色：

- **编解码状态 `zc`**：决定生成的起点（source）；
- **层级视觉先验 `P = (Pstr, Psem)`**：规定重建中应保留的语义内容与空间结构。

解码形式为：`ẑ0 = Gθ(zc; P)`，`x̂ = Dg(ẑ0)`，其中 `Gθ` 为一步潜变量映射（DiT 实现），`Dg` 为全程冻结的生成式 VAE 解码器。

### 2.2 比特流派生的视觉证据（共享接口）

- 熵解码与合成得到特征 `fc`，由此分两路：
  - **编解码状态**：`zc = Pc(fc)`，学习投影将 `fc` 放入与生成式 VAE 潜变量在空间尺寸和数值尺度上兼容的坐标，但**不约束为高斯分布**；
  - **证据图像**：`ex = De(fc)`，轻量证据解码器渲染出图像域表示，作为冻结视觉编码器（DINOv3、VAE）可解读的"共同接口"。
- `ex` 完全由接收比特流计算，**无需额外传输**；用辅助损失 `Lev = MSE(ex, x) + λev-sem·L_DINO_ev` 监督（像素重建 + DINOv3 逐深度 patch-token 余弦相似度），以保留源图布局、外观与语义。

### 2.3 层级视觉先验（互补条件）

- **多深度密集语义先验**：从冻结 DINOv3 的 L=4 个选定深度（第 6/12/18/24 块）提取空间 patch token（排除 class/register token），逐深度归一化并投影到 DiT 隐藏维度，得 `Psem = (Psem_1,…,Psem_L)`。
  - 关键设计：**不把多层坍缩为单一条件**，而是保留层级顺序，按 `γ(k)=1+⌊(k−1)L/K⌋` 将第 ℓ 级语义分配给第 ℓ 组连续 DiT 块，通过**深度匹配的交叉注意力**注入。
- **扩散原生结构先验**：用冻结 VAE 编码器 `S` 编码同一 `ex`，得 `Pstr = S(ex)`，同时 `z0 = S(x)` 为训练目标；`Pstr` 与演化潜变量在通道维拼接后进入 patch embedding，提供空间对齐的结构参考。
- **角色区分**：`zc` 决定"从哪里开始传输"，`Pstr` 是贯穿生成映射的结构参照，`Psem` 提供跨网络层次的语义抽象。

### 2.4 三阶段渐进式适配

| 阶段 | 目标 | 关键做法 |
|---|---|---|
| **Stage I：条件流适配** | 让生成轨迹锚定在传输证据上，同时保留随机性以便流学习 | 定义编解码中心源 `z1 = zc + σsϵ`（σs=0.3）；线性插值 `zt=(1−t)z0+t·z1`；训练速度预测器，损失 `LFM = E‖vθ(zt,t;P)−(z1−z0)‖²`，并联合优化码率项 `R` 与证据损失；采样不用 CFG |
| **Stage II：一步流映射蒸馏** | 把迭代传输蒸馏为直接一步映射 | 采用 AYF 的 Eulerian map distillation（AYF-EMD）；学生 `uθ(z,t,r;P)` 估计区间平均速度，固定 `r=0`，得 `Gθ(z;P)=z−uθ(z,1,0;P)`；教师为冻结的 Stage I 模型，学生由其权重初始化；**仅更新学生**，codec 与条件模块全部冻结 |
| **Stage III：噪声退火** | 消除训练–部署的源分布不匹配 | 令 `z1^(ρ)=zc+ρσsϵ`，`ρ` 按半余弦从 1 退火到 0（前 10k 步）；联合优化 codec、证据路径、语义投影与一步 DiT；损失 `LIII = λrate·R + Limg + λadv·L_DINO_adv + λev·Lev`，其中 `Limg` 组合 MSE、MS-SSIM、LPIPS、DISTS，对抗损失基于冻结 DINOv3 多深度特征的轻量判别头，30k 步后启用 |

- **设计逻辑**：不在一步内强加"随机→确定"与"迭代→一步"两个变化，而是分阶段解耦；`ρ` 的连续收缩避免了从随机源到确定性输入的突变。

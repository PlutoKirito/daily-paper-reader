ABSTRACT
Reward-guided image editing at test time seeks to improve a specified reward
while preserving source content and visual plausibility. Many existing approaches
optimize candidates through pretrained generation processes, making repeated ad-
justment depend on costly large-model execution and, in some cases, backbone
backpropagation. We develop a theoretical framework that jointly accounts for re-
ward, source preservation, and pretrained-prior preferences, allowing the desired
output distribution to be specified separately from the dynamics used to realize it.
Based on this framework, we introduce FASTER, which trains a small network
for each source and objective to perform inexpensive editing, while pretrained
and reward models provide feedback on candidate outputs. By reusing each can-
didate and its feedback across multiple small-network updates, FASTER reduces
repeated sampling and supervision queries without placing the pretrained gener-
ative backbone inside the inner optimization loop. On SD3, FASTER leads all
four target metrics and several validation metrics among the evaluated methods.
Compared with the evaluated baseline that optimizes controls along pretrained
generation trajectories, FASTER achieves editing-time speedups of up to 6.91×
on Stable Diffusion 3 and 24.14× on Stable Diffusion 1.5.

INTRODUCTION
Pretrained diffusion and flow models provide rich visual priors for image generation (Ho et al.,
2020; Song et al., 2021; Rombach et al., 2022; Lipman et al., 2023; Liu et al., 2023; Esser et al.,
2024). However, their conditioning interfaces do not fully express every downstream objective: hu-
man preferences, reference styles, and task-specific semantic requirements may instead be specified
through rewards available at test time. Reward-guided inference adapts generated outputs to such
objectives without retraining the pretrained model (Bansal et al., 2023; Yu et al., 2023; Ye et al.,
2024; Tang et al., 2025; Eyring et al., 2024; Susladkar et al., 2026). We focus on reward-guided
image editing at test time: given a source image and a reward objective, improve the objective while
retaining content that need not change and maintaining visual plausibility (Chang et al., 2026). Un-
like unconstrained reward maximization, this task requires meaningful, source-preserving changes;
a higher reward alone does not establish a successful edit.
Existing approaches typically inject reward guidance into pretrained generation or optimize candi-
dates through a generation mapping or trajectory. Guidance methods use external gradients to adjust
intermediate states, with refinements to the guidance geometry and update rules (Chung et al., 2023;
Bansal et al., 2023; Yu et al., 2023; He et al., 2024; Yang et al., 2024; Ye et al., 2024; Susladkar
et al., 2026). Optimization-based approaches instead adjust input noise, editable variables, or tra-
jectory controls to improve the generated output (Wallace et al., 2023; Ben-Hamu et al., 2024; Tang
et al., 2025; Eyring et al., 2024; Chang et al., 2026). Other advances improve efficiency through
reward optimization of one-step models, flow-based editing, or efficient reward guidance (Eyring
et al., 2024; Patel et al., 2025; Huang et al., 2026). Despite their different computational costs, many

decoding and reward-computation costs. Can pretrained knowledge continue to constrain desirable

Figure 1 contrasts optimization along pretrained generation trajectories with FASTER’s lightweight
editing process: the former repeatedly executes the large generative backbone, whereas the latter
uses a small network to perform editing with feedback from frozen models. We establish a theo-
retical basis for this separation by jointly analyzing reward improvement, source preservation, and
pretrained-prior plausibility, specifying a target output distribution and constructing an independent
editing process that realizes it under ideal conditions. Each task fixes a source and an objective, so
the learned editor need only adapt the current instance rather than acquire general-purpose genera-
tion capabilities.
Based on this framework, we introduce FASTER: a small network trained at test time performs inex-
pensive editing updates, while pretrained and reward models provide feedback at candidate outputs.
Reusing each candidate and its feedback across multiple network updates reduces repeated sampling
and costly supervision queries. To support explicit semantic changes that increasing an image–text
score may fail to produce, we further introduce an editing term that obtains semantic directions from
the pretrained model’s conditional predictions, without backpropagation through its backbone. This
term enters the same feedback interface, allowing the lightweight editor to use pretrained semantic
knowledge while retaining its inexpensive update process. On Stable Diffusion 3 (Esser et al., 2024),
FASTER leads the target metric in all four tasks and several validation metrics among the evaluated
methods. Relative to the evaluated baseline that optimizes controls along pretrained generation tra-
jectories, it achieves editing-time speedups of up to 6.91× on Stable Diffusion 3 (Esser et al., 2024)
and 24.14× on Stable Diffusion 1.5 (Rombach et al., 2022).
Our contributions are threefold:
• Decoupling the editing target from its dynamics. We combine reward, source preser-
vation, and pretrained-prior preferences into a target distribution, and construct separate
lightweight dynamics that realize it under proper conditions theoretically.
• FASTER: inexpensive editing with a small network. A per-image small network exe-
cutes inexpensive edits and reuses candidate feedback to reduce repeated computation. A
semantic editing term supplies directions from conditional model predictions through the
same interface, without generative-backbone backpropagation.
• Editing quality and efficiency across tasks. FASTER leads all four target metrics and
several validation metrics in the SD3 comparison, with up to 6.91× and 24.14× speedups
on SD3 and SD1.5, respectively. A 768 × 768 SD3 ImageReward edit takes approximately
7.7 seconds on a single consumer GPU.

RELATED WORK
Inference-time guidance and alignment.
Training-free guidance steers pretrained diffusion and
flow models toward external objectives without updating model weights. DPS, Universal Guidance,
and FreeDoM construct guidance from denoised predictions or external energies (Chung et al., 2023;
Bansal et al., 2023; Yu et al., 2023), while MPGD, DSG, and TFG further improve the geometry
and design of guidance (He et al., 2024; Yang et al., 2024; Ye et al., 2024). Alternatively, DOODL
and D-Flow optimize latent variables through the pretrained generative mapping (Wallace et al.,
2023; Ben-Hamu et al., 2024), with DNO and ReNO improving robustness or efficiency of direct
optimization (Tang et al., 2025; Eyring et al., 2024). Distributional methods such as DAS and
Feynman–Kac steering instead reshape inference through reweighting and resampling (Kim et al.,
2025; Singhal et al., 2025). These approaches provide flexible test-time alignment, but generally
remain coupled to pretrained generation during optimization.
Training-free and reward-guided image editing.
Training-free image editing must also preserve
source correspondence. Existing methods use inversion and attention control (Hertz et al., 2023b;
Mokady et al., 2023), controlled corruption (Meng et al., 2022), and feature reuse (Tumanyan et al.,
2023; Cao et al., 2023). Other approaches rely on score differences (Hertz et al., 2023a) or directly
model source-to-target editing dynamics (Xu et al., 2024; Kulikov et al., 2025). For reward-guided
editing, ITOC optimizes controls along the pretrained trajectory (Chang et al., 2026). FlowChef
exploits flow geometry (Patel et al., 2025), whereas RewardFlow combines multiple differentiable
rewards (Susladkar et al., 2026). FMRG further improves guidance efficiency through flow-map
lookahead (Huang et al., 2026). FASTER instead specifies a source-conditioned endpoint target and
learns a separate lightweight transport to realize it.
Generative priors and stochastic-control optimization.
Frozen models provide priors for in-
verse imaging (Feng et al., 2023; Feng & Bouman, 2024; Mardani et al., 2024) and score-distillation-
based 3D optimization (Poole et al., 2023; Wang et al., 2023). UniDB formulates diffusion bridges
as SOC with a tunable terminal penalty (Zhu et al., 2025), while UniDB++ accelerates sampling
within this framework through a training-free solver (Pan et al., 2026). For SOC solvers, Adjoint
Matching learns controls by regression (Domingo-Enrich et al., 2025), Adjoint Sampling reuses ter-
minal information through reference bridges (Havens et al., 2025), and Efficient Adjoint Matching
simplifies the reference dynamics and terminal cost (Shin et al., 2026). FASTER uses frozen-model
endpoint supervision to learn a lightweight per-image editor.

EXPERIMENTS
Following Chang et al. (2026), we evaluate four reward-guided editing tasks with 300 source–
condition pairs each. Human preference optimizes ImageReward (Xu et al., 2023). Style transfer
minimizes the Gram-matrix difference between output and reference-image features from CLIP ViT-
B/16 (Radford et al., 2021). Counterfactual generation maximizes the target-class logit of a robust
ResNet-50 classifier (Engstrom et al., 2019), using a class label as the reward condition. Text-guided
facial editing maximizes CLIP ViT-L/14 image–text similarity for the requested attribute. Each task
also reports validation metrics not directly optimized: HPSv2 (Wu et al., 2023), CLIPScore, and
Aesthetic for human preference; reference-image CLIP-I and DINO (Caron et al., 2021) similarity
for style; target-class text CLIPScore for counterfactual generation; and ImageReward and HPSv2
for facial editing. These metrics assess whether target improvements generalize beyond the opti-
mized reward.
We use Stable Diffusion 3 Medium (SD3) (Esser et al., 2024) for the main quality comparison.
The baselines are ITOC (Chang et al., 2026), gradient ascent (GA), DPS (Chung et al., 2023),
FreeDoM (Yu et al., 2023), TFG (Ye et al., 2024), and MPGD (He et al., 2024); GA performs
gradient ascent in latent space. Appendix F details the datasets, reward models, evaluation protocol,
and baseline implementations, and provides the SD1.5 results.
5.1
MAIN RESULTS
FASTER achieves the best target metric in all four SD3 tasks and leads several validation metrics
(Table 1). For human preference, the ImageReward improvement is accompanied by the high-
est HPSv2 and CLIPScore; for counterfactual generation, both the target-class logit and validation
CLIPScore lead the comparison. Facial editing similarly combines the highest target CLIPScore
with the best ImageReward. In style transfer, FASTER achieves the lowest GramDiff and highest
reference CLIP-I, although its DINO similarity remains below the best result. These gains extend
to multiple metrics that are not directly optimized, although FASTER does not lead every validation
metric.
Alongside these quality results, FASTER offers a substantial editing-time advantage over the base-
line that optimizes controls along pretrained generation trajectories (Fig. 3). FASTER achieves
speedups of up to 6.91× on SD3 and 24.14× on SD1.5. This advantage is consistent with assigning
repeated updates to a small network and reusing costly endpoint feedback. A 768 × 768 SD3 Im-
ageReward edit takes approximately 7.7 s of editing time on a single consumer GPU. Appendix F
gives the timing protocol, memory measurements, and comparisons with all baselines.

CONCLUSION
We introduced a decoupled view of reward-guided image editing at test time, in which pretrained
models provide visual knowledge while a separate lightweight process executes the edit. Our the-
oretical framework jointly accounts for reward improvement, source preservation, and prior prefer-
ences, establishing a basis for specifying desirable outputs independently of pretrained generation
9


Preprint.
trajectories. Building on this framework, FASTER trains a small per-image network and reuses
candidate outputs and their costly feedback across multiple inexpensive updates. A complementary
editing term obtains semantic directions from conditional model predictions without backpropagat-
ing through the pretrained backbone, supporting changes that image–text score maximization alone
may fail to produce. Across four tasks, FASTER achieves competitive target and independent vali-
dation metrics, with editing-time speedups of up to 6.91× on SD3 and 24.14× on SD1.5 relative to
the evaluated baseline that optimizes controls along pretrained generation trajectories.

FINITE UPDATES AND REPLAY
For a general frozen endpoint law ρk, the regression mean is taken under ρk(z1)Qτ(dzλ | z1).
The proof establishes the target fixed point, not a one-step exact solution or global convergence.
In practice, endpoints follow the current controller law and Eq. (11) uses an approximate prior
score; either change breaks the exact fixed-point premise. Equation (12) conditions on one detached
endpoint and label per refresh. This empirical objective need not have the population minimizer
even if that endpoint came from the target. Resampling bridges supplies stochastic gradients of this
frozen empirical objective, not new independent terminal information. The next refresh replaces the
stored pair; retaining older endpoints would instead define a replay variant.

E.1
ENDPOINT-QUERY REUSE
With K endpoint refreshes and one candidate per refresh, the basic loop computes K endpoint tar-
gets, up to the chosen number of noisy-score samples per candidate. Its KM controller updates
reuse those targets and draw new bridge times and noises. Each refresh also requires N evalua-
tions of the small controller for Euler–Maruyama simulation. These counts describe the algorithmic
placement of expensive queries; actual runtime depends on decoder, score-model, controller, and
optimizer costs. Differentiation through the decoder is confined to the endpoint-query step. Since
the targets are detached, the inner regression loop does not build or retain computation graphs for
the pretrained model.

Frozen inputs.
We instantiate the four tasks of Chang et al. (2026) with 300 frozen
source/condition pairs per task. Human-preference sources use prompts from the Reward Feed-
back Learning (ReFL) data released with ImageReward (Xu et al., 2023); style sources are from the
Pick-a-Pic test split (Kirstain et al., 2023) and are paired with five fixed style-reference images; coun-

counterfactual targets, we select a nearby ImageNet class using a WordNet IS-A graph (Miller,
1995).
Baseline implementations.
• ITOC (Chang et al., 2026) iteratively optimizes an image-conditioned sampling trajectory
using reward adjoints.
• Gradient Ascent (GA) directly updates the editable latent using the task-reward gradient.
• DPS (Chung et al., 2023) applies posterior-style reward guidance during reverse sampling
after source inversion. This is the source-editing adaptation used in the ITOC comparison
suite.
• FreeDoM (Yu et al., 2023) uses its training-free energy guidance after source inversion,
with the same frozen source set.
• TFG (Ye et al., 2024) uses training-free reward guidance during the corresponding
inversion-conditioned reverse trajectory.

Preprint.
• MPGD (He et al., 2024) updates a predicted clean endpoint with the reward gradient. On
SD1.5 we use an MPGD-LDM source-edit variant; on SD3 we use a flow-edit adaptation.

inversion and guidance mechanisms are intrinsic to the baselines. We report mean metric values.
Target and validation definitions.
Human preference directly optimizes ImageReward and addi-

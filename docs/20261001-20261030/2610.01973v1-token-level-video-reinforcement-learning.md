## 摘要
视频生成的强化学习（RL）通常为整个采样视频分配一个标量奖励。然而，视频并非均匀存在缺陷：一些视觉 token 可能已经满足提示，而另一些则需要修正。标量奖励无法定位错误，导致优化扰动令人满意的 token，而对真正需要改变的 token 关注不足。我们提出 Token 级视频强化学习（TVRL），一个从待优化奖励中推导 token 级信用分配的框架。我们的关键洞见是，冻结视觉语言模型的答案似然提供两种信号：其输出构成视频级奖励，而其视频输入梯度的幅值揭示哪些生成视频 token 对该得分影响最大。我们在 Group Relative Policy Optimization 中实例化 TVRL：将提示推导的问题奖励平均为一个组相对优势，并使用分离的、以问题为条件的 token 信用图，在裁剪策略比率内对稠密去噪转移对数概率重新加权。在 VBench-2.0 上，TVRL 取得 57.69 的 Overall 分数，比基础模型高 3.60 分。TVRL 还在三个 SDE 采样器（SAGE、Flow 和 Dance）上使匹配的 GRPO 基线提升 2.68--3.15 分，并在四个奖励模型（VideoAlign、VideoScore2、UnifiedReward2 和 Qwen3.5-9B）上提升 1.33--3.15 分。

## Abstract
Reinforcement learning (RL) for video generation usually assigns one scalar reward to an entire sampled video. Yet a video is not uniformly flawed: some visual tokens may already satisfy the prompt, whereas others require correction. A scalar reward cannot localize errors, causing optimization to perturb satisfactory tokens while under-targeting the tokens that actually need to change. We introduce Token-Level Video Reinforcement Learning, TVRL, a framework that derives token-level credit from the reward being optimized. Our key insight is that the answer likelihood of a frozen vision-language model provides both signals: its outputs contribute to the video-level reward, while magnitudes of its video-input gradients reveal which generated video tokens most affect that score. We instantiate TVRL in Group Relative Policy Optimization by averaging prompt-derived question rewards into one group-relative advantage and using detached, question-conditioned token-credit maps to reweight dense denoising-transition log-probabilities inside the clipped policy ratio. On VBench-2.0, TVRL achieves an Overall score of 57.69, outperforming the base model by 3.60 points. TVRL also improves matched GRPO baselines across three SDE samplers (SAGE, Flow, and Dance) by 2.68--3.15 points and across four reward models (VideoAlign, VideoScore2, UnifiedReward2, and Qwen3.5-9B) by 1.33--3.15 points.

## 1. 核心问题与研究背景

- **研究动机**：视频生成的强化学习（RL）后训练通常给整段采样视频分配**单一标量奖励**。然而视频并非均匀存在缺陷——部分视觉 token 已满足提示，另一些才需要修正。
- **信用分配瓶颈**：标量奖励只能对完整去噪轨迹排序（哪条更好），却**无法定位**是哪些 token / 帧导致成功或失败。直接广播同一标量优势会把更新容量浪费在与评估误差无关的区域，同时欠修正真正需要改变的区域。
- **现实需求**：许多提示要求的证据只出现在小区域或少数帧中，例如“钢琴而非普通键盘”“玫瑰金表壳”“萤火虫是否出现”“镜头是否向右平移”等，都需要时空局部化的信用分配。
- **现有工作不足**：
  - 可微奖励方法（如 Diffusion-DRF）把奖励梯度直接回传到生成器，需要同时保留奖励模型、解码器与多步去噪图，内存开销大，且沿随机链的重复 Jacobian 乘积易放大不稳定梯度。
  - 稠密反馈方法（时间偏好标签、稠密描述、patch 级奖励模型）需要额外标注或单独训练局部奖励模型。
  - ViPO / 结构化对齐系统虽把标量优势重新分配到更细单元，但其分配图来自**感知先验**而非产生奖励的检查本身。
- **核心洞见**：奖励的**输入梯度幅值**天然携带“评分对局部变化有多敏感”的路由信号；关键在于让被微分的评分与希望定位的语义要求**对齐**。冻结 VLM 的教师强制答案似然恰好同时提供：①视频级奖励；②以问题为条件的敏感度图。

## 2. 方法论

### 2.1 核心思想

- 视频级奖励决定 rollout 被强化还是抑制；显式的 **token 级信用分布**决定该更新在视频 token 上如何分配。
- 在旧策略处的未裁剪代理梯度可写为：`−A_i · Σ_g w_{i,g} · ∇_θ u^θ_{i,t,g}`，其中 `A_i` 为 rollout 优势，`u^θ` 为局部策略得分，`w_{i,g} ≥ 0` 且 `Σ_g w = 1`。
- **均匀信用即退化为标量 GRPO**；ViPO 从感知特征导出 `w`；TVRL 则从**奖励自身的输入梯度**导出 `w`。

### 2.2 关键技术细节

1. **随机策略与视频接地检查**：
   - 扩散 Transformer 定义随机转移 `π_θ(z_{t−1} | z_t, t, c)`；SDE 采样器用噪声调度 `σ_{η,t}` 扰动均值 `μ^sde_θ`，对数概率为 `−‖z_{t−1} − μ^sde_θ‖² / (2σ²_{η,t}) + const`。
   - 离线用语言模型把每个提示分解为 `K` 个原子 yes/no 检查 `Q(c) = {q_j(c)}`，每个检查只针对一个可直接从视频验证的要素（主体、属性、动作、关系、场景、镜头等）。
   - 所有检查及固定参考答案放入结构化 schema，在**一次教师强制 VLM 前向**中打分。

2. **教师强制奖励与 token 信用**：
   - 问题奖励：`R_{i,j} = (1/|A_{i,j}|) Σ_{ℓ∈A_{i,j}} log p_φ(a_ℓ | x_i, a_{<ℓ})`，即参考答案 token 的平均对数概率。
   - 对同一评分关于处理后的视频帧输入 `ξ_i` 求导，得到梯度 `g_{i,j} = ∇_{ξ_i} R_{i,j}`。
   - 按信用粒度 `Γ` 聚合、对齐并归一化：`w̃ = Agg_Γ(|g|)`，`w = w̃ / max(Σ w̃, ε)`。
   - 作者称 `|g|` 为**奖励敏感度图**：一阶意义上衡量评分对每个视频 token 小幅扰动的变化；它是局部、模型相关的敏感度，而非因果归因。

3. **共享 rollout 优势**：
   - 先在每个 rollout 内对 `K` 个问题奖励求平均，再在提示组内归一化：`Ā_i = (1/K)Σ_j R_{i,j}`，`A^tvrl_i = (Ā_i − μ_G) / max(σ_G, ε)`。
   - 所有检查共享同一 `A_i`，并通过各自的信用图路由；失败的检查也可能获得正优势，因为图只负责**分配**视频级奖励，而非监督每个问题。

4. **Token 级策略更新**：
   - 对每个信用单元 `Ω_g` 内的稠密转移对数概率取平均得 `u^θ_{i,t,g}`，加权求和得 `ℓ^θ_{i,t,j} = Σ_g w_{i,j,g} u^θ_{i,t,g}`，再构造单一加权策略比率 `ρ = exp(ℓ^θ − ℓ^θold)`。
   - TVRL 代理目标：`L_tvrl = (1/TMK) Σ_{i,t,j} max(−Â_i ρ, −Â_i clip(ρ, 1−ε, 1+ε))`。
   - 未裁剪区域梯度：`∇L ∝ −Â_i ρ Σ_g w_{i,j,g} ∇_θ u^θ`——优势决定符号与整体强度，信用图决定时空分配。
   - 在旧策略处所有 `ρ = 1`，`K` 张图的一阶效果等价于其平均 `w̄`；但通过指数化与裁剪后，单一平均图比率反而更差（附录 A.4 验证）。

5. **KL 正则化**：沿用 SAGE-GRPO 的参考 KL 项 `D_ref` 与逐步旧策略 KL 项 `D_step`，自适应更新 `β_KL`；token 信用只影响裁剪策略比率项。

### 2.3 算法流程（文字版）

1. 对每个提示离线分解出 `K` 个 yes/no 检查及固定参考答案。
2. 旧策略对同一提示采样 `M` 条 rollout（视频）。
3. 冻结 VLM 对每条视频做一次教师强制打分，得到 `K` 个问题奖励。

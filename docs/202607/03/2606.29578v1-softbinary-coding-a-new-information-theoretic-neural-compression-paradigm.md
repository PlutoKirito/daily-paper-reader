## 摘要
神经压缩目前主要由非线性变换编码（NTC）主导，它通过连续变换将数据映射到实值潜变量。尽管取得了成功，但NTC存在由于不可微分量化导致的训练-测试不匹配、连续变换固有的“平滑偏差”使得某些源无法达到最优，以及由于包含高维矢量量化的复杂性而失去“整形增益”等问题。我们提出软二进制编码（SBC），这是一种端到端的学习范式，通过使用随机二进制潜空间绕过了这些限制。本着矢量量化的精神，SBC使用离散表示，并通过一种新颖的快速二进制信道仿真方案对其进行压缩，我们为该方案提供了速率最优性的证明。在信息论源上的实验增益从理论和实践上解决了NTC的限制，确立了离散二进制结构作为达到最优率失真界限的可行途径。令人惊讶的是，SBC在独立同分布源矢量量化上也达到了最先进的性能，超过了高斯源的网格编码量化。

## Abstract
Neural compression is currently dominated by Nonlinear Transform Coding (NTC), which maps data to real-valued latents via continuous transforms. Despite its success, NTC suffers from train-test mismatch due to non-differentiable quantization, a ``smoothness bias" inherent in continuous transforms that precludes optimality for certain sources, and a loss of ``shaping gain" due to the complexity of including high-dimensional vector quantization. We propose SoftBinary Coding (SBC), an end-to-end learning paradigm that bypasses these limitations by using a stochastic binary latent space. In the spirit of vector quantization, SBC employs discrete representations and compresses them through a novel fast binary channel simulation scheme, for which we provide a proof of rate optimality. Experimental gains on information-theoretic sources provide both theoretical and practical closure to NTC's limitations, establishing discrete binary structures as a viable path toward reaching optimal rate--distortion bounds. Surprisingly, SBC also achieves state-of-the-art performance on vector quantization of i.i.d. sources, exceeding Trellis Coded Quantization of the Gaussian source.

## 1. 核心问题与整体含义（研究动机和背景）

- **背景**：当前神经压缩领域的主流范式是非线性变换编码（NTC），它使用连续神经网络将数据映射为实值潜变量，再通过取整量化与算术编码实现压缩。NTC在图像、视频、点云等模态上取得了显著成功。
- **核心问题**：NTC存在三个根本性缺陷：
  1. **训练‑测试不匹配**：硬量化操作不可微，训练时需使用可微近似（如均匀噪声），导致训练损失与真实压缩性能不一致。
  2. **连续变换的“平滑性偏差”**：连续映射难以表示源所需的尖锐不连续结构（如圆上分支切割、随机跳跃点），从而无法达到理论最优率失真界。
  3. **形状增益（shaping gain）损失**：NTC通常采用标量量化，难以实现高维矢量量化（VQ）带来的形状增益，且VQ的计算复杂度极高。
- **论文目标**：提出一种全新的端到端学习范式——软二进制编码（SoftBinary Coding, SBC），使用随机二进制潜空间，通过快速信道模拟实现离散表示的压缩，理论上达到最优速率，同时在多个信息论源上超越NTC和现有最佳方案（如网格编码量化TCQ）。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- 用**随机二进制潜变量**（{0,1}^L）替代NTC中的实值潜变量。
- 潜变量采样自参数化的伯努利分布：`Z_i ~ Bern((1+V_i)/2)`，其中`V_i = fθ(X_i) ∈ (-1,1)`。
- 编码器输出`V`，解码器通过**信道模拟**（channel simulation）在未知源X的情况下生成潜变量Z，实现“软”通信。

### 关键技术
1. **信道模拟范式**：
   - 将压缩问题转化为通信问题：编码器将源信息`V`通过一个二进制输出信道`P(Z|V)`传递给解码器，解码器利用共享随机性生成Z。
   - 理论速率下界为`I(V; Z)`，即互信息。
   - 传统信道模拟方案（如随机编码）计算复杂度指数级，不可行。

2. **快速二进制信道模拟——PolarSim的泛化**：
   - 基于极化码（polar codes）的思想，利用**源极化**（source polarization）将独立但非同分布的二进制输出信道极化，使大部分子信道的互信息接近0或1。
   - 对极化后的子信道采用简单校正方案（`∆=Z⊕˜Z`），其速率损失随极化程度消失。
   - 论文提出了**PermutedPolarTransform**，在递归极化变换前加入随机置换，并证明**非平稳源的极化定理**（Theorem B.1）：极化后，条件熵在(δ, 1-δ)之外的子信道比例趋于0。
   - 算法流程（Algorithms 1 & 2）：
     - **编码器**：对于每个极化子信道i，计算源条件概率`Q_i`和无源条件概率`P_i`，使用共享均匀随机数`s_i`生成`˜u_i`和`u_i`，计算差异`∆_i = u_i ⊕ ˜u_i`，然后对`∆^N`进行无损算术编码。
     - **解码器**：利用共享随机数和概率表解码∆^N，恢复`u_i`，再通过逆极化变换得到原始潜变量Z^N。
   - 复杂度为`O(N log N)`，与PolarSim一致。

3. **端到端训练**：
   - 训练目标：`R + λD`，其中`R = E[D_KL(qθ ∥ pψ)]`，`D = E[d(X, ˆX)]`。
   - 由于潜变量离散，采用**VarGrad**梯度估计器（Richter et al., 2020），提供无偏低方差的梯度。
   - 为减少初始化依赖，采用三种随机初始化选最优，并加入逐步衰减的L2正则项`∥fθ(X)∥²`。

4. **操作方案**：
   - 将多个源样本的潜变量拼接成大块（N=2^23），利用PolarSim的长块极化增益。
   - 通过蒙特卡洛估计每个潜比特的KL散度，剔除贡献极小的比特（阈值<总KLD的1/1000），提高效率。

## 3. 实验设计

### 数据集/场景
- **信息论源**（可计算理论最优）：
  - **Circle**：2D流形，`X=(cosθ, sinθ)`，θ~U(0,2π)。测试编码器处理不连续分支的能力。
  - **Ramp**：`X_t = [(t+β) mod 1] - 1/2`，β~U(0,1)。测试解码器处理随机跳跃的能力。
  - **i.i.d. Gaussian**：`X ~ N(0,1)`，经典量化基准。
  - **i.i.d. Uniform**：`X ~ U(-1/2, 1/2)`，测试熵模型处理尖锐边界的能力。
- **分布式压缩场景**（Wyner-Ziv）：两个相关高斯源，侧信息Y仅在解码端可用。包括`X=Y+N`和`Y=X+N`两种情况，噪声方差0.1。

### Benchmark与对比方法
- **NTC**：基线方法，L=1（或2在Circle中），使用Agustsson & Theis (2020)的退火过程处理量化不可微。
- **SBC**：L=4,8,32（根据源复杂度），使用Arithmetic coding + PolarSim。
- **理论界**：One-shot entropy-distortion bound（Bhadane et al., 2022），Wyner-Ziv R-D bound，点对点R-D bound。
- **经典方法**：TCQ（Trellis Coded Quantization，256状态），DISCUS（分布式压缩），Lei et al. (2025)的格型量化方案（Λ24 Leech lattice）。

### 关键结果
- **Circle**：NTC在L=1时远差于理论界；SBC（L=8）接近理论界，且获得形状增益。
- **Ramp**：NTC在高码率时无法恢复跳变；SBC（L=4,8）超过理论界（形状增益）。
- **分布式压缩**：SBC（L=32）优于NTC、DISCUS和先前学习方案，接近Wyner-Ziv界。
- **i.i.d. Gaussian**：SBC（L=32）超越TCQ和格型方案，接近率失真函数（+1.53dB偏移为ECSQ空间填充损失）。
- **i.i.d. Uniform**：SBC（L=32）与TCQ一致，NTC因熵模型平滑偏差性能较差。

## 6. 主要结论与发现

1. **SBC直接解决NTC三大缺陷**：训练-测试匹配（通过信道模拟统一目标）、消除平滑偏差（离散潜空间）、获得形状增益（高维二进制表示）。
2. **SBC的速率最优性**：基于源极化的信道模拟方案被证明是渐近最优的（Theorem 3.1）。
3. **SBC在多个信息论源上达到或超越理论最优**：在Circle、Ramp、Gaussian、Uniform等源上均优于NTC，在Gaussian源上刷新了TCQ保持的记录。
4. **SBC在分布式压缩中自然实现“装箱”（binning）**，而NTC因连续偏差难以做到。
5. **SBC不需要复杂的熵模型**（如超先验或自回归模型），而是将概率建模负担转移到信道模拟部分，简化实现。

## 8. 不足与局限

- **实验范围有限**：仅测试了低维（1D/2D）信息论源，未在图像、视频等实际高维数据上验证，是否能推广至实际应用存疑。

## 摘要
在本文中，我们提出TECO，一种多维剪枝框架，通过协同剪枝卷积神经网络（CNN）的三个维度（深度、宽度和分辨率）以提高在嵌入式硬件上的执行效率。在TECO中，我们首先引入一个两阶段重要性评估框架，该框架根据每个维度内的局部重要性和跨维度的全局重要性，高效且全面地评估每个剪枝单元。基于该评估框架，我们提出一种启发式剪枝算法，逐步剪枝CNN的三个维度，以在准确性和效率之间实现最优权衡。多个基准实验验证了TECO相对于现有最先进方法的优势。代码与预训练模型可在https://github.com/ntuliuteam/Teco获取。

## Abstract
In this paper, we propose TECO, a multi-dimensional pruning framework to collaboratively prune the three dimensions (depth, width, and resolution) of convolutional neural networks (CNNs) for better execution efficiency on embedded hardware. In TECO, we first introduce a two-stage importance evaluation framework, which efficiently and comprehensively evaluates each pruning unit according to both the local importance inside each dimension and the global importance across different dimensions. Based on the evaluation framework, we present a heuristic pruning algorithm to progressively prune the three dimensions of CNNs towards the optimal trade-off between accuracy and efficiency. Experiments on multiple benchmarks validate the advantages of TECO over existing state-of-the-art (SOTA) approaches. The code and pre-trained models are available at https://github.com/ntuliuteam/Teco.

#### 1. 论文的核心问题与整体含义（研究动机和背景）

#### 2. 论文提出的方法论：核心思想、关键技术细节、公式与算法流程
- **核心思想**：采用两阶段重要性评估（局部 + 全局）准确识别冗余剪枝单元，并基于启发式算法逐步剪枝三个维度，逐步逼近最优小型架构。
- **关键技术细节**：
  - **内维度重要性评估（INES）**：在残差块内引入通道门（CG）和层门（LG），通过一次反向传播获得所有门梯度的平方作为局部重要性，快速识别每个维度内最不重要的单元（通道/层）。分辨率维度由于统一缩放图像，不执行 INES。
  - **跨维度重要性评估（ITES）**：对 INES 选出的三个单元（深度、宽度、分辨率各一个），计算其全局重要性，综合考虑对精度损失 A(u)、MACs 减少 M(u) 和延迟减少 T(u) 的影响。公式：\[ I(u) = \frac{A(u)}{\alpha M(u) + (1-\alpha) T(u)} \]，其中 A(u) 为交叉熵损失增加，T(u) 通过维度级延迟线性模型 \( l_s = a_s m + c_s \) 估算。
  - **启发式架构下降算法**：迭代执行 INES → ITES → 剪枝 → 微调（1 epoch，lr=1e-4），逐步移除全局重要性最低的单元，直至满足资源预算。完全剪枝后模型从头训练得到最终精度。
- **算法流程**（文字说明）：
  1. 给定过参数化模型 N 和评估数据集 Dv（5000 张随机训练图像）。
  2. 每次迭代：运行 INES 获取各维度内局部重要性，选出深度 d*、宽度 w*、分辨率 r* 三个候选单元。
  3. 运行 ITES 计算三个候选单元的全局重要性，选择最低者进行剪枝。
  4. 微调模型 1 epoch 恢复精度。
  5. 重复迭代 n 次（典型值 10 次），得到最终剪枝模型 Np，再从头训练。

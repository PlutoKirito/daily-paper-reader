## 摘要
基于大语言模型的无损图像压缩方法通常通过预训练模型的原生文本接口表示像素数据，将像素值转换为LLM通过其词表头处理的标记序列。这种设计表明，预训练语言模型可以为图像编码提供概率估计，但同时也将压缩与分词器行为、词汇特定的数字标记以及模型家族特定的适配耦合在一起。在本文中，我们提出LUMI（基于LLM的统一模型无关无损图像压缩），这是一个无需分词器的框架，用于使用冻结的LLM骨干网络进行无损RGB图像压缩。LUMI用像素嵌入模块替换了像素即文本的标记化方法，该模块将原始强度和通道信息映射到LLM的连续嵌入空间。它还引入了块内位置编码，以在展平后保留二维空间结构，并使用256路预测头来生成原生像素字母表上的概率。仅训练像素嵌入、位置编码、软前缀参数和预测头，而LLM骨干网络保持固定。在使用LLaMA、Qwen和Gemma骨干网络的自然图像、医学图像和遥感图像基准上的实验表明，LUMI提供了跨分词器家族的统一接口，实现了有竞争力的压缩率，并提高了基于分词器的LLM压缩基线在跨域鲁棒性方面的表现。这些结果将基于LLM的无损图像压缩归结为冻结基础模型的像素空间适配，而不是特定于分词器的语言符号建模。

## Abstract
Large language model (LLM)-based lossless image compression methods typically represent pixel data through the native text interface of a pretrained model, converting pixel values into token sequences that the LLM processes through its vocabulary head. This design shows that pretrained language models can provide probability estimates for image coding, but it also couples compression to tokenizer behavior, vocabulary-specific numeric tokens, and model-family-specific adaptation. In this paper, we present LUMI (LLM-based Unified Model-agnostic lossless Image compression), a tokenizer-agnostic framework for lossless RGB image compression with frozen LLM backbones. LUMI replaces pixel-as-text tokenization with a pixel embedding module that maps raw intensity and channel information into the continuous embedding space of the LLM. It further introduces intra-patch position encoding to retain two-dimensional spatial structure after flattening, and uses a 256-way prediction head to produce probabilities over the native pixel alphabet. Only the pixel embedding, position encoding, soft-prefix parameters, and prediction head are trained, while the LLM backbone remains fixed. Experiments on natural, medical, and remote-sensing image benchmarks with LLaMA, Qwen, and Gemma backbones show that LUMI provides a unified interface across tokenizer families, achieves competitive compression rates, and improves cross-domain robustness over tokenizer-based LLM compression baselines. These results formulate LLM-based lossless image compression as pixel-space adaptation of frozen foundation models rather than tokenizer-specific language-symbol modeling.

## 1. 核心问题与整体含义（研究动机和背景）
- **现有方法的缺陷**：基于大语言模型（LLM）的无损图像压缩方法（如 P²-LLM）将像素值转换为文本数字 token 后送入 LLM 进行概率估计。这种方式紧密耦合于特定的分词器（tokenizer）行为——不同 LLM 家族（如 LLaMA、Qwen、Gemma）对同一像素值“255”可能拆分为不同数量的 token（LLaMA 为 1 个，Qwen 和 Gemma 为 3 个），导致序列长度、词汇事件定义不同，压缩接口无法跨模型复用。
- **核心问题**：如何设计一种与分词器无关的、统一的像素表示和概率估计接口，使得冻结的 LLM 骨干网络可以作为通用的熵模型用于无损图像压缩，同时保持竞争力压缩率和跨域鲁棒性。

## 2. 方法论
- **核心思想**：将像素值直接映射到 LLM 的连续嵌入空间，绕过文本分词器，并在输出端使用专用的 256 路预测头（pixel head）输出像素级概率分布，仅训练外部接口模块，冻结 LLM 骨干。
- **关键技术细节**：
  - **像素嵌入模块（PixEmb）**：对每个子像素构造 7 维描述符（包含归一化强度、多项式项、三角特征和通道独热编码），通过两层 GELU MLP 映射到 LLM 嵌入维度 d。
  - **块内位置编码（INP）**：对每个 16×16 补丁，学习行位置表和列位置表，通过门控求和得到每个子像素的空间编码，与像素嵌入相加形成最终表示。
  - **LLM 处理流程**：将训练软前缀（soft prefix）、文本任务提示（task prompt）的嵌入以及前 t-1 个像素的表示拼接后输入冻结的 decoder-only LLM，获取第 t 个位置隐藏状态。
  - **256 路预测头**：将 LLM 隐藏状态映射到 256 维 softmax 分布，直接对应 0-255 像素值的概率，用于算数编码。
  - **训练策略**：仅训练 PixEmb、INP 参数、软前缀和预测头，LLM 骨干参数完全冻结。损失函数为交叉熵（teacher forcing）。

## 3. 实验设计
- **数据集与场景**：
  - **自然图像**：Kodak（24 张，12 训练/12 测试）
  - **医学图像**：BRACS 组织病理图像（12 张，4 训练/8 测试）
  - **遥感图像**：BED4RS（60 张，30 训练/30 测试，选取山和森林子集）
  - 所有图像转为 RGB，分割为不重叠的 16×16 补丁（每个补丁 768 个子像素）。
- **Benchmark 与对比方法**：
  - 传统编解码器：JPEG-XL、DLPR（深度有损+残差）
  - LLM 基线：LLaMA (P²-LLM Vanilla)、LLaMA (P²-LLM LoRA)
  - LUMI 使用三个 LLM 骨干：Llama-3.2-3B、Qwen3-8B、Gemma-3-4B
- **评估指标**：bits per pixel（BPP），越低越好，所有解码图像经无损验证。

## 6. 主要结论与发现
- LUMI 在所有三个域内数据集上取得竞争力 BPP，**平均高于 JPEG-XL 和 DLPR**（如 Kodak 上 LUMI LLaMA 8.56 对比 JPEG-XL 8.95）。
- **跨域泛化实验中**，LUMI 仅使用其他两个域训练，仍能接近甚至超越 JPEG-XL 和 DLPR，显著优于基于分词器的 P²-LLM 基线。
- 消融实验证明：
  - PixEmb 比文本分词表示更有效（7-D 变体比 P²-LLM Vanilla 降低 3.55~7.72 BPP）。
  - INP 进一步带来显著增益（约 3~7 BPP 提升）。
  - 任务提示和软前缀互补，联合最佳。
- LUMI 对骨干网络规模和数据量均呈现一致正刻度。

## 7. 优点
- **分词器无关（Tokenizer-Agnostic）**：同一压缩接口可直接应用于不同 LLM 家族（LLaMA/Qwen/Gemma），无需针对特定分词器修改。
- **轻量适配**：仅训练少量外部参数（PixEmb、INP、软前缀、预测头），LLM 骨干完全冻结，降低了训练成本和对骨干的依赖。
- **跨域鲁棒性**：训练在某一域后，可直接迁移至其他域，性能退化有限。
- **结构化的像素表示**：通过多项式、三角、通道独热等工程化设计，在嵌入空间中形成按强度和通道排列的规则结构（可视化验证），利于熵建模。
- **扩展性强**：骨干越大、数据越多，压缩率持续提升，表明框架可受益于基础模型缩放。

## 8. 不足与局限
- **独立补丁处理**：当前将每个 16×16 补丁独立建模，无法利用补丁间长程依赖，限制了压缩潜力。论文承认这一限制，留作未来工作。
- **解码延迟高**：自回归 LLM 推理导致显著解码延迟，远高于传统编解码器（文中引用相关文献指出）。
- **性能受限于骨干**：由于 LLM 骨干冻结，LUMI 只能改善输入表示，无法超越骨干本身固有的预测能力。
- **未评估其他 LLM 架构**：仅测试了 LLaMA、Qwen、Gemma 三个系列，未涉及更大规模（如 70B）或其他架构（如 Mamba）。
- **训练数据规模较小**：医学和遥感数据训练补丁分别仅数千到数万，可能限制泛化统计稳定性。

## 摘要
自动回归上下文模型是学习图像压缩的基础，但它们存在串行推理速度慢的问题。现有的加速方法如棋盘格上下文需要修改架构和重新训练，因此不适用于预训练模型。我们提出了一种完全无需训练、仅在推理时加速的算法，灵感来自视频编码标准中的波前并行。我们的方法将推理重新组织为最优的“交错”波前顺序，在保持精确自回归依赖关系的同时最小化顺序步骤。实验结果表明，我们的方法在保持原始率失真性能的同时，将预训练的自回归模型（如 Cheng 等人）加速了 13 倍以上。我们还展示了通过权衡精确的上下文依赖关系可以实现更快的解码。源代码将在 https://github.com/tokkiwa/compressai-wavefront 提供。

## Abstract
Autoregressive context models are foundational for learned image compression,but they suffer from slow serial inference. Existing acceleration methods such as checkerboard context require architectural changes and retraining, thus are inapplicable to pre-trained models. We propose a completely training-free inference-time acceleration algorithm inspired by wavefront parallelism in video coding standards. Our method reorganizes inference into an optimal ``staggered'' wavefront order, minimizing sequential steps while maintaining exact autoregressive dependencies. Experimental results show our approach accelerates pre-trained autoregressive models (e.g., Cheng et al.) by more than $13\times$ while preserving the original rate-distortion performance. We also demonstrate that faster decoding is possible by trading off precise context dependencies. Source code will be available at https://github.com/tokkiwa/compressai-wavefront.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究动机**：学习图像压缩（LIC）中，自回归上下文模型（如Cheng2020、MBT2018、InvCompress）虽能有效捕捉空间相关性、实现优越的率失真（RD）性能，但其串行解码顺序（光栅扫描）导致推理瓶颈——解码需要 O(H×W) 个串行步骤，对高分辨率图像尤其耗时。
- **现有方法局限**：加速方案如Checkerboard上下文需修改模型架构并重新训练，不适用于预训练模型，且通常牺牲RD性能。通道自回归模型同样需要重新训练。
- **核心问题**：能否在不修改模型、不重新训练的前提下，对预训练的空间自回归模型实现并行加速，同时保持原有RD性能？

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- 将自回归上下文模型重新解释为定义在有向无环图（DAG）上的贝叶斯网络。每个像素（节点）的上下文依赖仅限于局部邻域，图是稀疏的。因此，标准光栅扫描不是最优调度；可以找到一种合法的拓扑序，使得多个节点在同一时间步并行解码。
- **波前调度**：利用Lamport超平面定理，设计线性调度函数 τ(i,j) = λ·i + j。其中λ为剪切因子（shear factor），对于 (2R+1)×(2R+1) 的掩码卷积，最小有效λ = R+1（例如5×5掩码对应λ=3）。该调度将网格点划分为对角线（波前），同一对角线上的像素互不依赖，可并行处理。
- **训练无关**：只需改变解码顺序，无需重训模型，兼容任何已有预训练权重。

### 关键技术细节
1. **波前并行化**：按τ值分组，同一组像素并行计算上下文（通过批处理卷积）。
2. **选择性Im2Col**：避免展开整个特征图，仅提取每个波前所需的局部块，减少内存开销。
3. **Tensorized rANS**：实现GPU友好的熵编码器（C++扩展），避免PyTorch与Python间的数据拷贝和同步。
4. **上下文近似模式**：为进一步加速，允许将N个连续波前合并为一个组，对组内尚未解码的像素用均值填充（或零填充）近似上下文。这种近似会略微增加比特率，但能成倍提升速度。

## 6. 主要结论与发现

- **速度提升**：波前并行化（WF）单独可带来13–14倍加速，结合TrANS后加速达26.7–35.7倍（Kodak），在CLIC2020-valid上最高达71.9倍。
- **RD性能保持**：波前并行化不改变任何模型参数或输出（仅浮点舍入误差<0.08%），BD-Rate与基线完全相同。
- **上下文近似模式**：N=2时比特率上升~9.7%，但解码加速~59倍；N=4时比特率上升~27.9%，解码加速~104倍。提供了实用的速度-速率权衡。
- **TrANS的重要性**：波前并行化后熵编码成为瓶颈，Tensorized rANS可额外带来2–3倍加速。

## 7. 优点

- **训练无关**：无需任何重新训练，可直接应用于任何预训练的空间自回归模型，实用性强。
- **理论严谨**：利用DAG建模和Lamport超平面定理，严格证明波前调度的有效性和最优性（最小串行步数）。

- **灵活的速度-质量权衡**：上下文近似模式允许用户在运行时调整并行度，无需换模型。

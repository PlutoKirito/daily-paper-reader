## 摘要
语义通信（SC）能够实现带宽高效的无线图像传输，但现有的大多数SC方案与用户无关，忽略了接收方相关的语义。为解决这一问题，我们提出了一种个性化数字语义通信（PDSC）框架，该框架将基于视觉语言模型（VLM）的语义编码器与基于潜在扩散模型（LDM）的语义解码器相结合。具体而言，语义编码器从源图像和接收方的历史交互中提取源感知的个性化语义标记。这些标记被向量量化成离散的语义索引，并进一步编码为紧凑的定长比特流，从而与数字传输兼容。在接收端，语义解码器根据恢复的语义标记重建个性化图像。此外，我们构建了一个容量受限的个性化语义率失真问题，并引入了一种语义失真度量，该度量同时表征源语义保真度和用户偏好对齐度。实验表明，在带宽受限的无线传输条件下，PDSC在源语义一致性和个性化方面优于最先进的SC基线方法（包括CDDM和MoS）。

## Abstract
Semantic communication (SC) enables bandwidth-efficient wireless image transmission, but most existing SC schemes are user-agnostic and ignore receiver-dependent semantics. To address this issue, we propose a personalized digital semantic communication (PDSC) framework that integrates a vision-language model (VLM)-based semantic encoder with a latent diffusion model (LDM)-based semantic decoder. Specifically, the semantic encoder extracts source-aware personalized semantic tokens from both the source image and the receiver's historical interactions. These tokens are vector-quantized into discrete semantic indices and further encoded into a compact fixed-length bitstream, enabling compatibility with digital transmission. At the receiver, the semantic decoder reconstructs a personalized image conditioned on the recovered semantic tokens. Furthermore, we formulate a capacity-constrained personalized semantic rate-distortion problem and introduce a semantic distortion metric that jointly characterizes source-semantic fidelity and user-preference alignment. Experiments show that PDSC achieves superior source-semantic consistency and personalization over state-of-the-art SC baselines, including CDDM and MoS, under bandwidth-limited wireless transmission.

- **背景**：

## 2. 论文提出的方法论

### 核心思想
- 通过 VLM 提取三类语义令牌：**偏好令牌（zp）**、**视觉语义令牌（zv）**、**文本语义令牌（zt）**，分别捕捉接收者个性化偏好、源图像结构信息和高层语义指导。
- 将连续语义令牌经**向量量化（VQ）**转换为离散索引，并编码为**定长比特流**，以兼容数字无线传输。
- 接收端使用**潜在扩散模型（LDM）** 基于收到的令牌重建个性化图像。

### 关键技术细节
- **个性化语义编码器**：
  - 使用冻结的视觉 tokenizer 提取源图像与历史交互图像的视觉令牌；
  - 通过 Transformer 编码器进行上下文增强；
  - 计算源令牌与历史令牌之间的双向最大余弦相似度，筛选相关令牌（训练时用 Gumbel-Softmax 实现可微掩码，推理时用硬 top-M 选择）；
  - 用交叉注意力从历史令牌中提取偏好令牌 zp；
  - 用可学习查询向量聚合源令牌得到视觉语义令牌 zv；
  - 用 BLIP 生成源图像描述，再经文本编码器得到文本语义令牌 zt。
- **向量量化数字接口**：
  - 每个语义令牌 zj 映射到码本中最近的码字，得到离散索引 kj；
  - 采用直通估计器（straight-through estimator）处理非可微量化；
  - VQ 损失包含码本更新损失和承诺损失；
  - 引入熵正则项避免码本坍缩。
- **容量约束下的语义率失真问题**：
  - 语义源速率 Rs = L⌈log2 K⌉，其中 L 为令牌数，K 为码本大小；
  - 信道容量 Cch = Nch log2(1+SNR)；
  - 优化目标为最小化期望个性化语义失真，约束 Rs ≤ Cch。
- **个性化语义失真度量**：
  - D(X, X̂, Hu) = α·L_sem(X, X̂) + (1−α)·L_pref(X̂, Hu)；
  - L_sem 为源图像与重建图像在预训练 VLM embedding 空间中的余弦距离；
  - L_pref 为重建图像与用户历史图像的加权相似度距离，权重由源图像与历史图像的相似度决定（softmax 归一化）。
- **扩散解码器**：
  - 条件注入方式：zp 通过交叉注意力引导个性化属性，zv 通过特征级线性调制（FiLM）调制 U-Net 特征，zt 提供文本语义指导；
  - 训练采用两阶段策略：
    - 阶段一：冻结预训练组件，仅训练语义编码器、投影层、码本，损失为 L_diff + λ_vq L_vq + λ_u L_u；
    - 阶段二：解冻解码器的条件注入模块，联合微调，增加个性化失真项 λ_s D。
- **推理流程**：提取语义令牌 → 量化 → 定长编码 → 信道编码与数字调制 → 信道解码 → 码本查表恢复令牌 → LDM 重建图像。

## 3. 实验设计：数据集、场景、Benchmark 与对比方法

- **数据集**：MovieLens-Latest 用户评分记录 + 对应电影海报图像。每个接收者选取 N=5 个正向评分海报作为历史偏好集 Hu。
- **场景**：AWGN 信道上的无线图像传输；测试不同 SNR（0~20 dB）和不同语义速率（147~231 bits/image）。
- **模型配置**：
  - VLM 模块基于 LaVIT；
  - 语义解码器基于 Stable Diffusion XL；
  - 令牌数：Lp=1, Lv=15, Lt=5，总 L=21；
  - 码本大小 K=1024（默认）；
  - 损失权重：λ_vq=1.0，λ_u=0.1，λ_s=1.0。
- **对比方法**：
  - BPG+LDPC：分离式像素压缩 + 信道编码方案；
  - CDDM：基于通道去噪扩散模型的语义通信基线；
  - MoS：混合物语义传输（Mixture-of-Semantics）基线。
- **评价指标**：
  - CIS（CLIP Image Score）：重建图像与用户历史图像之间的 CLIP 图像相似度，衡量用户偏好对齐；
  - CS（CLIP Score）：重建图像与源图像文本描述之间的 CLIP 相似度，衡量源语义一致性。

## 6. 论文的主要结论与发现

- PDSC 在所有测试 SNR 和速率下均优于 BPG+LDPC、CDDM 和 MoS。
- 在 0 dB 低 SNR 下，相比最强基线 MoS，PDSC 的 CIS 提升 45.8%，CS 提升 15.4%；在 20 dB 时仍分别提升 21.1% 和 5.7%。
- 在不同语义速率下（147~231 bits/image），PDSC 平均比 MoS 提升 CIS 23.1%、CS 6.7%。
- 性能增益来源于：① 利用接收者历史交互提取个性化语义，剔除与用户无关的信息；② 紧凑的离散语义索引对信道扰动更鲁棒；③ 扩散解码器利用生成先验补充视觉细节。
- 增加码本大小超过 K=1024 后性能增益趋于饱和，说明大部分有用的个性化语义已被捕获。
- CIS 比 CS 对 SNR/速率更敏感，说明个性化偏好信息的准确恢复比全局语义一致性更具挑战性。

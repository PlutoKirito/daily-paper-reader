## 摘要
均匀INT8量化对于部署学习型图像编码（LIC）具有吸引力，但其率失真（R-D）性能通常受到重尾张量和大的通道间变化的限制。现有方法主要通过混合精度或非均匀码本自适应量化器。我们提出了Hadamard变换域量化（HaTQ），它在量化之前使用正交Hadamard重参数化，将原始域中的权重和激活响应在通道间重新分布。这种重参数化保留了每个线性算子的原始函数映射，同时使其权重和激活更适合均匀INT8量化。HaTQ提供了两种互补的形式。双Hadamard量化同时变换输入激活和权重，而仅权重Hadamard量化只变换权重。这种区别很重要，因为恒定的Hadamard基可以相干地累积非零通道均值，并扩大敏感层中的激活范围。我们通过离线分析识别这些敏感层，并为每一层分配适当的形式，而无需依赖输入的分支。HaTQ支持训练后量化（PTQ）和量化感知训练（QAT），使用均匀INT8量化器，并且兼容仅整数执行。在具有代表性的LIC架构和数据集上的实验表明，在不同量化设置下均有一致的改进。所得的QAT模型进一步优于竞争的混合精度和非均匀量化方法。TensorRT部署结果证明了实用的INT8推理效率。源代码将公开发布。

## Abstract
Uniform INT8 quantization is attractive for deploying learned image coding (LIC), but its rate--distortion (R--D) performance is often limited by heavy-tailed tensors and large inter-channel variations. Existing methods mainly adapt the quantizer through mixed precision or non-uniform codebooks. We propose Hadamard-Transform-domain Quantization (HaTQ), which uses orthogonal Hadamard reparameterization before quantization to redistribute weight and activation responses in the original domain across channels. The reparameterization preserves the original function mapping of each linear operator, while making its weights and activations more amenable to uniform INT8 quantization. HaTQ provides two complementary forms. Double-Hadamard quantization transforms both the input activations and weights, whereas weight-only Hadamard quantization transforms only the weights. This distinction is important because the constant Hadamard basis can coherently accumulate a nonzero channel mean and enlarge the activation range in sensitive layers. We identify these sensitive layers through offline profiling and assign the appropriate form to each layer without input-dependent branching. HaTQ supports both post-training quantization (PTQ) and quantization-aware training (QAT), uses uniform INT8 quantizers, and is compatible with integer-only execution. Experiments on representative LIC architectures and datasets demonstrate consistent improvements across different quantization settings. The resulting QAT models further outperform competing mixed-precision and non-uniform quantization methods. TensorRT deployment results demonstrate practical INT8 inference efficiency. The source code will be publicly released.

## 一、核心问题与整体含义（研究动机与背景）

- **背景**：学习型图像编码（LIC）已从学术研究走向实际应用（如 JPEG AI、IEEE 1857.11 标准），但其模型复杂度高，部署时需要模型量化来降低存储、内存带宽与计算开销，并保证跨平台数值一致性（熵编码对编码器-解码器数值不一致极为敏感）。
- **核心问题**：均匀 INT8 量化具有硬件友好性，但 LIC 模型中的权重和激活常呈现**重尾分布**和**显著的通道间幅度差异**（如图 2 所示），少量极端值主导量化范围，使得主体数值在均匀网格上分辨率不足，导致显著的 R-D 性能退化。
- **现有方法的局限**：已有研究多从量化器侧入手——混合精度（mixed precision）为敏感层分配更多比特、非均匀量化（non-uniform）自适应布置量化网格。这些方法虽能提升精度，但引入异构位宽、特殊数值格式或不规则执行路径，削弱了与标准 INT8 推理后端（如 TensorRT）的兼容性，影响算子融合与调度效率。
- **核心洞见**：论文提出一个反向思路——**不改变量化器，而是改变被量化张量所处的表示域**。借鉴经典变换编码思想（transform coding），通过函数保持的正交 Hadamard 重参数化，让 LIC 模型的权重和激活在量化前变得更“均匀友好”，从而在保留硬件友好均匀 INT8 量化的同时恢复 R-D 性能。

## 二、方法论：核心思想、关键技术细节与算法流程

### 1. 核心思想
- **Hadamard 域量化（HaTQ）**：在线性算子（卷积/全连接层）的权重和激活进入量化器之前，施加正交 Hadamard 变换（Hadamard transform）。由于 Hadamard 矩阵的正交性，配对的变换在数学上相互抵消，**不改变原算子的函数映射**，但本质上将各通道的能量在变换域内重新混合，抑制通道局部化的极端响应，降低张量的超额峰度（excess kurtosis），从而更有效地利用均匀 INT8 整数网格。
- **实验支撑**：图 2 显示，Hadamard 变换使激活和权重的超额峰度分别降低 95.5% 和 97.6%；图 3 显示变换后激活的 SQNR 显著提高。

### 2. 两种互补形式
- **Double-Hadamard（DH）量化**：对激活和权重沿其收缩维度同时施加匹配的 Hadamard 变换，即 $Y_l = (X_l H^{in}_l)(W_l H^{in}_l)^\top$。变换因子在算子内部成对抵消，**无需输出侧基变换**。
- **Weight-only Hadamard（WH）量化**：仅对权重沿输出通道维度施加 Hadamard 变换，激活保持在原始域，在矩阵乘法累积完成后通过输出侧 Hadamard 变换恢复原始输出基，即 $Y_l = [X_l(H^{out}_l W_l)^\top] H^{out}_l$。
- **为何需要区分**：Hadamard 变换中的恒定基向量（constant basis）会相干地累加非零通道均值。激活函数（如 ReLU、GDN）可能引入跨通道非零均值，导致变换后出现新的极端最大值，反而扩大张量级量化范围（图 5 展示了这类“相干放大”现象）。

### 3. 离线逐层策略选择
- 使用 $M=1000$ 张图像计算每层的**范围扩张概率** $p_l = \frac{1}{M}\sum_k \mathbb{I}[\|H^{in}_l(X_{l,k})\|_\infty > \|X_{l,k}\|_\infty]$。
- 根据阈值 $\tau_{sel}=0.8$ 选择：$p_l > \tau_{sel}$ 的层使用 WH（避免激活侧变换），否则使用 DH。
- 分配结果在 PTQ、QAT 和推理过程中**固定不变**，无输入相关分支，不引入在线选择开销。

### 4. 整数执行支持
- 论文推导了 DH/WH 两种形式在相邻层间整数基转换的完整流程（表 I），包括输出侧/输入侧 Hadamard 变换的归一化因子吸收到定点缩放中（乘子-移位近似）、偏置处理、以及一般非线性（SiLU、GELU、GDN 等）的整数实现。
- Hadamard 变换本身仅需加减运算；权重侧变换离线折入卷积核，不增加运行时算子；激活侧变换以固定 1×1 卷积形式导出，兼容 TensorRT 等标准推理后端。
- 支持 PTQ（动态仿射激活量化 + 网络级联合校准）和 QAT（静态对称量化 + EMA 尺度跟踪）两种工作流，各有通道级和张量级两种量化粒度。

## 五、主要结论与发现

- **Hadamard 变换有效**：在所有四种量化设置（PTQ/QAT × CW/TW）下，带 Hadamard 变换的模型显著优于不带变换的对应设置（图 8），其中张量级激活 QAT 场景 BD-rate 从 +18.63% 降至 +4.29%。
- **QAT 性能全面优于现有一流方法**：GMM 通道级 QAT 平均 BD-rate 达 -3.86%，优于混合精度 FMPQ（+1.76%）和 DynaQuant（+1.82%）；ELIC 上 Kodak 仅 +0.16%（对比 DynaQuant +5.97%）。
- **PTQ 同样优于现有一流方法**：张量级 PTQ 上 HaTQ 平均 BD-rate +2.96%，大幅优于 AWDB-PTQ（+12.44%）和 SmoothQuant（INT9，+3.56%）。
- **均匀 INT8 可赶超非均匀/混合精度**：在合适的表示域中，均匀 INT8 量化可以胜过直接在原域做非均匀量化（SS-PTQ）或混合精度分配（FMPQ、DynaQuant），印证了“量化性能由坐标系统与量化器共同决定”的核心主张。
- **QAT 出现负 BD-rate**：论文对此做了合理解释——INT8 并不天然优于 FP32，而是 Hadamard 重参数化改善了 QAT 的训练条件，使模型收敛到更优 R-D 工作点。
- **层自适应选择必要**：无自适应选择时 BD-rate 从 4.29% 恶化至 9.30%，说明激活侧变换在敏感层（主要是上下文模块）会造成相干放大问题。
- **部署可行性**：TensorRT 实测（768×512）中 HaTQ 为 13.39 ms/张，比 FP32（24.80 ms）快 11.41 ms，比 INT8 基线（8.13 ms）慢 5.26 ms；Hadamard 系数存储仅增加 1.5 MB。当前开销主要来自 1×1 卷积的便携实现而非方法固有成本。

## 六、优点

1. **视角创新**：将经典变换编码原理推广到模型量化——与其设计更复杂的量化器，不如让被量化张量本身更可量化。这一思路简洁优雅且具有普适性。
2. **函数保持**：Hadamard 重参数化严格保持原线性算子的数值映射（正交矩阵配对抵消），属于无损变换，不像 SmoothQuant 等需要通道缩放来迁移量化难度。
3. **硬件友好**：统一 W8A8 均匀量化，无混合精度/非均匀格式；权重侧变换离线折叠，激活侧变换仅含加减或可表示为固定 1×1 卷积，兼容 TensorRT 整数执行，无需定制插件。
4. **无输入相关分支**：层策略离线固定，推理路径与普通 INT8 模型一致，无动态选择开销。
5. **支持多种工作流**：同时适用于 PTQ 和 QAT，通道级和张量级激活粒度可自由组合，实用性强。
6. **层自适应设计**：识别出恒定基相干累积放大效应，提出可操作的离线诊断指标（范围扩张概率），设计精细且分析扎实。
7. **实验质量高**：与多类主流方法（混合精度、非均匀、SmoothQuant 类域变换）对比，且控制了精度与量化粒度等条件，结论可信度高。

## 七、不足与局限

1. **TensorRT 便携实现引入额外开销**：在线 Hadamard 变换用 1×1 密集卷积实现，产生不必要的乘法、内存流量和内核启动开销（768×512 下比 INT8 基线多 5.26 ms/张，约 65% 开销）。论文仅在展望中提及专用核与算子融合，实际部署效率待优化验证。
2. **ELIC 实验覆盖不完整**：缺少 PTQ 结果，无法确认 PTQ 方法在 ELIC 上的迁移效果；表 III 中 Tecnick 的通道级 QAT 结果（+6.33%）明显高于 Kodak（+0.16%）和 CLIC（+0.63%），论文未对此差异进行解释。
3. **Hadamard 矩阵存在性受限**：并非所有通道维度都存在对应阶数的 Hadamard 矩阵，需填充到最近支持阶数（Sylvester/Paley/Kronecker 构造）。填充引入了额外通道计算，但论文未报告填充带来的参数量/计算量开销。
4. **QAT 负 BD-rate 现象解释较简略**：将负 BD-rate 归因于“改善训练条件”，但未提供损失景观、收敛轨迹或训练动态的定量证据，作为现象的一种开放性解释尚可，但不构成严谨的因果分析。
5. **可推广性讨论不足**：所有实验均为图像编码模型（GMM/ELIC），未涉及视频编码或生成式 LIC 架构（如扩散式解码器）；论文声称可迁移至神经视频编码，但缺乏实证。
6. **评估指标单一**：仅用 PSNR 作为失真度量，未评估 MS-SSIM、LPIPS 等感知指标，也未报告编码/解码分离延迟（实际部署中编码端常更为关键）。
7. **细节透明度有限**：未明确说明 Hadamard 核的顺序选择（Paley-II 等的具体构造）、填充比例对效率的影响、灵敏度分析（$\tau_{sel}$ 与 $M$ 的选择依据）、多 GPU 或混合精度训练时 50 epoch 是否足够等。

ABSTRACT
Neural video codecs derive motion and temporal contexts mainly from RGB
frames, leaving room for cross-modal guidance from complementary temporal
observations. Event streams can provide such observations by recording bright-
ness changes between frames. In this work, we propose an Event-guided Neu-
ral Video Codec (ENVC) that uses events shared by the encoder and decoder
to improve RGB compression efficiency. For motion coding, ENVC forms an
event-guided motion prior and codes the remaining motion residual. For frame
coding, an event-conditioned predictor supplies multi-scale features for gated
temporal context refinement.
To support training and evaluation on standard
video datasets, we synthesize paired RGB–event data and assess its predictive
utility through comparisons with real events.
Across six benchmarks, ENVC
achieves average BD-rate savings of 39.13% using PSNR-RGB and 67.63% us-
ing LPIPS relative to DCMVC. Further analyses show that our gains persist on
large-motion sequences and that ENVC effectively learns to integrate event in-
formation. These results demonstrate the potential of events as a complementary
modality for reducing the RGB coding rate. Our model and code are available at
https://github.com/kjungwoo03/ENVC.

INTRODUCTION
Video accounts for a large share of network traffic, making efficient video compression a central
problem in visual communication. Neural video codecs (NVCs) optimize their coding modules
jointly under an end-to-end rate–distortion (RD) objective (Lu et al., 2019). Conditional coding
methods, which code the current frame using temporal contexts built from previously decoded in-
formation, have demonstrated RD gains over conventional codecs (Li et al., 2021; 2023). The qual-
ity of these contexts therefore strongly affects the bitrate needed for a given reconstruction quality.
Accordingly, recent studies have refined context modeling via multi-scale propagation (Sheng et al.,
2022), reference-guided modulation (Tang et al., 2025), and non-local multi-reference mining (Jiang
et al., 2025).
Despite these advances, temporal contexts in the RGB-only framework (Fig. 1a) depend only on
previously decoded frames and propagated features. Diverse motion patterns can make prediction
from these references less reliable, while reconstruction errors can accumulate over long prediction
chains. In both cases, more RGB information may be needed to maintain reconstruction quality. We
therefore ask whether complementary observations of inter-frame changes can improve temporal
contexts and reduce the required RGB bitrate.
To investigate this possibility, we focus on event streams, which asynchronously record brightness
changes between video frames. An event is triggered whenever the magnitude of the log-intensity
change at a pixel exceeds a contrast threshold, with its polarity indicating the sign of the change.
This mechanism yields microsecond-level temporal resolution and a high dynamic range (Gallego
et al., 2022). These properties have motivated a range of recent event-based methods for motion

A reference frame and inter-frame events can be used to reconstruct the current frame directly, as
illustrated in Fig. 1b. However, without additional current-frame RGB information, prediction errors
can limit reconstruction fidelity (Zhu et al., 2024a; Kong et al., 2025). We instead consider RGB
coding with events shared by the encoder and decoder (Fig. 1c). Both sides use these events to
construct temporal contexts, while a bitstream carries additional current-frame RGB information to
improve reconstruction quality. Similar shared-side-information settings have been explored in prior
work on cross-modal compression (Gnutti et al., 2024; Jiang et al., 2024; Song et al., 2026), and we
discuss practical scenarios in App. A.
In this work, we investigate how shared event observations can reduce the RGB rate required for
reconstruction.
We propose an Event-guided Neural Video Codec (ENVC) that incorporates
these observations into motion coding and temporal context construction. ENVC forms an event-
guided motion prior at both the encoder and decoder and codes the remaining motion residual. For
frame coding, an event-conditioned predictor generates a frame prediction and multi-scale features.
Learned gates inject these features into temporal contexts, which are further refined using the frame
prediction.
To train and evaluate ENVC on standard NVC datasets, we generate paired events from their RGB
videos through frame interpolation and event simulation (Sec. 3). We assess the utility of the syn-
thetic events by comparing event statistics and next-frame prediction quality with those obtained us-
ing real events. Across six standard video coding benchmarks paired with synthetic events, ENVC
achieves average BD-rate savings of 39.13% using PSNR-RGB and 67.63% using LPIPS (Zhang
et al., 2018) relative to DCMVC (Tang et al., 2025) under the shared-event setting. Our evaluation
further analyzes event utilization, motion-dependent performance, sensitivity to event perturbations,
and RD differences between real and synthetic event inputs.
Our contributions can be summarized as follows:
• We investigate shared events as a complementary modality for RGB video compression and pro-
pose ENVC, which combines event-guided residual motion coding with gated temporal context
refinement.
• We construct paired RGB–event datasets for standard NVC training and evaluation, and assess the
synthetic events through comparisons with real events in terms of event statistics and next-frame
prediction quality.
• We demonstrate substantial RGB coding gains across six standard benchmarks using PSNR-RGB
and LPIPS under the shared-event setting. These gains persist on large-motion sequences, sup-
porting the use of events as temporal guidance for RGB video coding.

Event-based Frame Reconstruction.
Event-only methods reconstruct intensity frames from
event streams (Rebecq et al., 2019; Weng et al., 2021; Zhu et al., 2024b), although events do not
directly measure absolute intensity (Gallego et al., 2022). Frame-guided methods combine RGB
images and events for interpolation (Tulyakov et al., 2021; 2022) or prediction from a single ref-
erence (Zhu et al., 2024a; Kong et al., 2025; Wang et al., 2025). Single-reference prediction is
compatible with sequential decoding, as a previously reconstructed frame can serve as the reference
without requiring future RGB frames. ENVC uses event-based prediction to guide compression and
codes additional current-frame RGB information under an RD objective.
Cross-modal Guidance for Compression.
Joint visible–infrared and RGB–depth codecs exploit
inter-modality redundancy (Lu et al., 2022; Zheng & Gao, 2024). Auxiliary modalities also guide
RGB compression as geometric (Gnutti et al., 2024; Jiang et al., 2024) or semantic side informa-
tion (Jiang et al., 2023; Lee et al., 2024; Hu et al., 2026), including semantic residual coding (Ke
et al., 2025) and text-conditioned latent refinement for machine vision (Lee et al., 2025). Depth-
assisted video compression uses geometric priors for temporal context and entropy modeling (Sheng
et al., 2026). Our work first investigates shared events as temporal side information, using their
observations of inter-frame brightness changes to guide motion coding and temporal context con-
struction.

Cheon & Lee, 2018). We therefore synthesize events from these RGB datasets using the pipeline in

4
PROPOSED METHOD
In this section, we introduce Event-guided Neural Video Codec (ENVC), and describe how ENVC
leverages shared events to predict motion and refine temporal contexts for conditional frame coding.
4.1
FRAMEWORK OVERVIEW
Fig. 4a illustrates the overview pipeline of ENVC, inspired by the conditional coding framework of
DCVC-DC (Li et al., 2023) and DCMVC (Tang et al., 2025). Both encoder and decoder use the
reconstructed reference ˆXt−1 and shared events Et−1:t. The Event-conditioned Frame Predictor
(EFP) produces a frame prediction Pt and multi-scale event-conditioned contexts. We estimate
motion from Pt relative to ˆXt−1, while the Residual Motion Codec (RMC) codes the difference
between the current-frame and event-based motion estimates. Adding the decoded residual to the
event-based estimate yields the reconstructed motion (Sec. 4.2).
Event-guided Context Refinement (ECR) aligns reference features using the reconstructed mo-
tion, then refines them through gated event injection and multi-scale fusion. Prediction-guided
Context Fusion (PCF) further incorporates features extracted from Pt into the ×1 context (Sec. 4.3).
The resulting temporal contexts condition frame encoding, entropy modeling, and reconstruction
(Sec. 4.4).

EXPERIMENTAL DETAILS
Training Details.
We train ENVC on Vimeo-90K (Xue et al., 2019) septuplet sequences paired
with synthetic events. We adopt staged training followed by cascaded fine-tuning with up to 32

5.2
RATE–DISTORTION PERFORMANCE
Figs. 5 and 6, together with Tab. 2, summarize the RD performance. Across six benchmarks, ENVC
achieves average BD-rate savings of 39.13% using PSNR-RGB and 67.63% using LPIPS relative to
DCMVC. These results show that shared events can reduce the RGB rate required for reconstruction
under both pixel-wise and perceptual quality measures. An analysis of P-frame bit allocation in
App. G further shows reduced motion coding rates relative to DCMVC.
On HEVC-E, PSNR-RGB savings are smaller (7.76%), while LPIPS-based savings remain substan-
tial (51.60%). The smaller PSNR-RGB gains are consistent with limited inter-frame motion and the
high I-frame share of the total RGB rate (56.2% at Q0), which limits the impact of event-guided
P-frame improvements. Sequence-level gains and failure cases are further analyzed in App. C.
Since ENVC is trained on synthetic events, we further examine how its RD performance changes
when real events are used instead. Comparisons using real and synthetic event inputs on paired
RGB–event datasets are provided in App. D.

5.4
EFFECTS OF MOTION MAGNITUDE AND INTRA PERIOD
Motion Magnitude.
We examine how our coding gains vary with the motion magnitude. Follow-
ing DCVC-RT (Jia et al., 2025), we measure motion using SEA-RAFT (Wang et al., 2024a) optical
flow between consecutive original frames. On 30 MCL-JCV sequences (96 frames each, intra period
32), ENVC achieves an overall BD-rate saving of 52.28% over DCMVC.
At the sequence level, the large-motion group achieves a saving of 56.60%, compared with 47.96%
for the small-motion group (Fig. 8a). We further examine this relationship at the frame level by
grouping only P-frames into four motion quartiles. From the lowest to the highest motion quartile,
BD-rate savings are 40.8%, 69.3%, 74.8%, and 65.9%, respectively (Fig. 8b). Although the largest
saving occurs in the third quartile, the highest-motion quartile still shows substantial gains. To-
gether, these results indicate that event guidance remains useful across different motion magnitudes,
including sequences and frames with large motion.
Longer Intra Periods.
On seven UVG sequences, we examine how longer intra periods affect
RGB coding rate and reconstruction quality. Relative to K = 32, increasing K to 64, 96, and 192
reduces mean bpp by 25.7%, 33.3%, and 37.7%, with PSNR-RGB losses of 0.37, 0.77, and 1.21
dB, respectively (Fig. 8c). Increasing K from 32 to 64 provides the largest incremental rate saving.
Further increases yield smaller additional savings while reconstruction quality continues to decline.

6
DISCUSSION
Our results suggest that events are a promising complementary modality to guide RGB video com-
pression. This motivates further research on efficient event coding and joint compression of RGB
frames and event streams. Jointly modeling the dependencies between these modalities could fur-
ther exploit cross-modal redundancy and improve overall coding efficiency, extending the present
framework toward joint RGB–event compression.
As an initial exploration of RGB coding with shared events, ENVC focuses on integrating event
information into motion coding and temporal context construction. The current implementation
requires event-conditioned prediction and motion estimation at both the encoder and decoder, in-
troducing additional computational overhead. Developing lightweight event-guidance modules and
efficient coding pipelines to reduce complexity and end-to-end latency remains an important direc-
tion for future work.
7
CONCLUSION
In this work, we presented ENVC, which incorporated events as a complementary modality for
RGB video compression through event-guided residual motion coding and gated temporal context
refinement. Across six benchmarks with synthetic events, ENVC achieved average BD-rate savings
of 39.13% using PSNR-RGB and 67.63% using LPIPS relative to DCMVC. Further analysis showed
scale-dependent event injection, while longer intra periods revealed a growing rate–quality trade-off.
These results demonstrate the potential of shared event observations as a complementary modality
for reducing the RGB coding rate.

PRACTICAL SCENARIOS
In this paper, we mainly consider systems that already transmit or retain events for downstream
processing and additionally require RGB video. Event cameras offer high temporal resolution, wide
dynamic range, and reduced motion blur (Gallego et al., 2022), with commercial implementations
including DAVIS3463 and Sony–Prophesee-based industrial cameras.4
Recent studies demonstrate event-based object detection (Ahmed et al., 2025), continuous-time 3D
detection (Kang et al., 2025), and monocular depth estimation (Bartolomei et al., 2025), while
TESPEC studies representations across detection, segmentation, and depth estimation (Mohammadi
et al., 2025). These capabilities give applications a reason to preserve event streams independently
of RGB compression.
For example, a robotic or industrial system may send events to a server for perception while pro-
viding RGB video for human inspection. An event-based detector can identify a moving object, but
an operator may still need its color, appearance, and surrounding context to interpret the prediction.
Displaying detections or trajectories over RGB frames connects machine outputs to an interpretable
view of the scene. Both streams may also support machine processing: EventDrive combines events,
RGB, and language for driving-related perception, prediction, and planning (Lu et al., 2026). When
these computations share a receiving endpoint, the RGB decoder can reuse the events already deliv-
ered for perception.
Related cross-modal compression methods use shared LiDAR depth maps (Gnutti et al., 2024) or
sparse point clouds (Jiang et al., 2024) to assist RGB image coding, while RangeCM uses RGB
camera context for LiDAR compression (Song et al., 2026). ENVC applies this principle to shared
event information. With the event stream held fixed across RGB codecs, its transmission or storage
cost is common to the compared systems. Our reported rate therefore measures the additional RGB
coding cost. Both coding ends use the same available event representation, and App. A.1 examines
sensitivity to compression-induced event degradation.
A.1
SENSITIVITY TO EVENT COMPRESSION
Motivation.
In the transmission and archival scenarios discussed above, the events available at
the receiver may themselves have undergone compression. Existing approaches include temporal
aggregation followed by video coding (Brites & Ascenso, 2025), point-cloud-based coding (Huang
& Ebrahimi, 2023), and learned lossless and lossy codecs (Sezavar et al., 2024; Seleem et al., 2026),
and the JPEG XE initiative further reflects the practical need for efficient event representation and
interoperability.5 Lossless coding preserves the coded representation, whereas lossy coding trades
event fidelity for rate reduction. Prior work therefore evaluates compressed events through their
effects on downstream tasks, including recognition, video reconstruction, optical flow, and depth
estimation (Huang et al., 2023; Seleem et al., 2025). In our setting, the decoded event stream can
likewise be reused as shared side information at both RGB coding ends. This motivates evaluating
how event coding quality affects its usefulness for RGB reconstruction in ENVC.
Settings.
To examine this setting, we evaluate a fixed ENVC checkpoint on the first 96 frames of
seven UVG sequences, using synthetic events, an intra period of 32, and quality Q0. For each inter-
frame interval, positive and negative events are represented as separate (x, y, t) point clouds (Huang
& Ebrahimi, 2023) and compressed using G-PCC (TMC13)6. Timestamps are mapped to an integer
grid before coding, and the decoded events undergo the original voxelization and normalization and
are supplied to both coding ends without fine-tuning. We vary the event quality factor qE, corre-
sponding to the quantization scale, where smaller values produce coarser coordinate quantization,
and qE = 1 is lossless for the coded integer-coordinate representation.
Results.
Fig. 9 shows that qE = 1 reproduces the original-event PSNR-RGB of 34.90 dB. At qE =
0.95, PSNR-RGB decreases to 33.52 dB, and at qE = 0.5 it reaches 30.70 dB, a 4.20 dB reduction.

B
TRAINING DETAILS
Progressive Training.
We adopt five training stages to first establish event-based prediction and
then optimize its integration into the codec. First, we train EFP and EME using frame prediction
and motion-compensated reconstruction losses, without rate losses (R). Second, we train RMC to
balance motion-compensated reconstruction quality against the rate of the coded motion residual.
Third, we train the context refinement modules and conditional frame codec while keeping the event
and motion modules fixed. This stage combines frame reconstruction distortion, frame coding rate,
and the decoupling loss of DCMVC (Tang et al., 2025). Fourth, we jointly optimize all inter-frame
modules, including CME, under the complete RD objective with both motion and frame coding
rates. The last stage extends this joint optimization to longer sequences (beyond the seven-frame
septuplets) through cascaded training.
Both EME and CME are initialized with the SPyNet weights from DCMVC (Tang et al., 2025). We
use the pretrained intra-frame codec of DCVC-DC (Li et al., 2023) for I-frame coding and keep it
fixed throughout training.
Cascaded Training.
We progressively increase the training sequence length from 8 to 16, 24, and
32 frames and minimize the RD loss averaged over all P-frames in each sequence. To reduce mem-
ory consumption, we use Forward Recomputation Backpropagation (FRB), as in DCMVC (Tang
et al., 2025). This approach recomputes intermediate activations during backpropagation instead
of retaining them all in memory (Chen et al., 2016), enabling optimization over longer prediction
chains.
Training Data.
We use Vimeo-90K septuplets (Xue et al., 2019) paired with synthetic events. For
cascaded training, we use 9,220 training clips and 106 validation clips extracted from the original
Vimeo videos7, each containing 32 frames with paired synthetic events. Events are represented as
signed voxel grids with 10 temporal bins. Training uses aligned random crops of 256 × 256 pixels,
reduced to 128 × 128 for the final 32-frame stage.
Optimization.
We train a single multi-rate model with λ ∈{85, 170, 380, 840} and periodic frame
weights (0.5, 1.2, 0.5, 0.9) following DCVC-DC (Li et al., 2023). Distortion combines YUV420 and
RGB MSE with weights 0.8 and 0.2, respectively. We use AdamW (Loshchilov & Hutter, 2017) with
weight decay 0.01 and train on four NVIDIA A100-SXM4-40GB GPUs.

results suggest that improving the reconstruction of largely static content, together with adapting
event guidance to sparse-event inputs, is a promising direction for increasing coding efficiency on
HEVC-E.

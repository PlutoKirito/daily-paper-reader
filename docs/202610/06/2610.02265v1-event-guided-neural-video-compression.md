## 摘要
神经视频编解码器主要从 RGB 帧中提取运动和时间上下文，这为来自互补时间观测的跨模态引导留下了空间。事件流可以通过记录帧间亮度变化来提供此类观测。在这项工作中，我们提出了一种事件引导的神经视频编解码器（ENVC），它利用编码器和解码器共享的事件来提高 RGB 压缩效率。对于运动编码，ENVC 形成事件引导的运动先验，并对剩余运动残差进行编码。对于帧编码，一个事件条件预测器提供多尺度特征，用于门控时间上下文细化。为了支持在标准视频数据集上的训练和评估，我们合成了配对的 RGB-事件数据，并通过与真实事件的比较来评估其预测效用。在六个基准上，相对于 DCMVC，ENVC 在使用 PSNR-RGB 时平均节省 39.13% 的 BD-rate，在使用 LPIPS 时平均节省 67.63%。进一步分析表明，我们的增益在大运动序列上仍然存在，并且 ENVC 能够有效学习整合事件信息。这些结果证明了事件作为补充模态在降低 RGB 编码码率方面的潜力。我们的模型和代码可在 https://github.com/kjungwoo03/ENVC 获取。

## Abstract
Neural video codecs derive motion and temporal contexts mainly from RGB frames, leaving room for cross-modal guidance from complementary temporal observations. Event streams can provide such observations by recording brightness changes between frames. In this work, we propose an Event-guided Neural Video Codec (ENVC) that uses events shared by the encoder and decoder to improve RGB compression efficiency. For motion coding, ENVC forms an event-guided motion prior and codes the remaining motion residual. For frame coding, an event-conditioned predictor supplies multi-scale features for gated temporal context refinement. To support training and evaluation on standard video datasets, we synthesize paired RGB-event data and assess its predictive utility through comparisons with real events. Across six benchmarks, ENVC achieves average BD-rate savings of 39.13% using PSNR-RGB and 67.63% using LPIPS relative to DCMVC. Further analyses show that our gains persist on large-motion sequences and that ENVC effectively learns to integrate event information. These results demonstrate the potential of events as a complementary modality for reducing the RGB coding rate. Our model and code are available at https://github.com/kjungwoo03/ENVC.

## 1. 核心问题与研究动机

- **背景**：视频占网络流量很大比重，神经视频编解码器（NVC）在端到端率失真（RD）目标下联合优化编码模块。条件编码方法（如 DCVC 系列、DCMVC）利用已解码信息构建时序上下文，上下文质量直接决定给定重建质量所需的码率。
- **问题**：现有 NVC 的运动与时序上下文**完全依赖 RGB 帧**（已解码帧与传播特征）。面对多样运动模式时预测可靠性下降，重建误差还会沿长预测链累积，导致需要更多 RGB 信息维持质量。
- **核心设问**：能否引入**帧间变化的互补观测**来改进时序上下文、降低 RGB 码率？
- **选择事件流的原因**：事件相机异步记录帧间亮度变化（对数强度变化超过对比阈值即触发，极性表示变化方向），具有微秒级时间分辨率与高动态范围，已在运动分析、帧重建/插值中展现价值。
- **关键设定区分**（图 1）：
  - (a) 纯 RGB 视频编码；
  - (b) 事件重建：仅用参考帧+事件直接重建当前帧，无当前帧 RGB 码流，但保真度受限；
  - (c) **事件引导视频编码（本文）**：编码器与解码器**共享事件**，双方用事件构建时序上下文，同时仍传输当前帧 RGB 码流以提升质量。
- **意义**：首次将共享事件作为时序侧信息用于 RGB 视频压缩，探索跨模态互补模态降低 RGB 编码码率的可行性。

## 2. 方法论

### 2.1 总体框架
- 基于 DCVC-DC 的条件编码框架与 DCMVC 的上下文调制，编码器与解码器均使用重建参考帧 X̂_{t-1} 与共享事件 E_{t-1:t}。
- 三大模块：**事件条件帧预测器（EFP）**、**残差运动编解码（RMC）**、**事件引导上下文细化（ECR）**，并含预测引导上下文融合（PCF）。

### 2.2 事件条件帧预测（EFP）
- 以 VFPSIE 为骨干，输出帧预测与多尺度上下文：  
  `(Pt, {C^{E,s}_t}_{s=0..2}) = P_θ(X̂_{t-1}, Vt)`
- 事件表示为**带符号事件体素网格** `Vt ∈ R^{10×H×W}`，按线性权重分配到相邻时间 bin。
- 图像与事件特征由独立编码器提取，经**跨模态注意力**的由粗到细解码器估计光流并合成 RGB 帧；预测 Pt 由合成帧与前向 warp 的参考帧融合得到。
- 多尺度上下文取自解码器 ×1/2、×1/4 输出，另设上下文头从最终解码阶段中间特征生成 ×1 上下文。

### 2.3 残差运动编码（RMC）
- 为对齐参考，估计**后向运动**而非复用 EFP 内部前向流：  
  `m^E_t = M_E(Pt, X̂_{t-1})`（事件运动估计器，编解码端均计算）  
  `m^X_t = M_X(Xt, X̂_{t-1})`（当前帧运动估计器，仅编码端计算）
- 仅编码运动残差：`Δmt = m^X_t − m^E_t`，重建为 `m̂t = m^E_t + Δm̂t`。
- 运动熵模型使用超先验与已重建运动潜变量。

### 2.4 事件引导上下文细化（ECR）
- **参考特征对齐**：从传播解码特征或 X̂_{t-1} 构建多尺度参考特征，用 m̂t 后向 warp 对齐；×1 处用偏移多样性（learned offsets + masks）细化。数值稳定性条件：初始 ×1 上下文最大绝对值超 5 时从 X̂_{t-1} 重新生成。
- **门控多尺度事件注入**：`C^{A,s}_t = C^{R,s}_t + G^s_t ⊙ A^s(C^{E,s}_t)`，其中 A^s 为零初始化适配器，G^s_t 为由 Vt 与 X̂_{t-1} 生成的**单通道 sigmoid 门控图**（广播到所有通道）。多尺度融合沿 ×1/4→×1/2→×1 自顶向下进行。
- **预测引导上下文融合（PCF）**：用 Pt 提取特征，经 DCMVC 的 base/detail 融合模块与 ×1 上下文融合并加回；三尺度上下文裁剪到 [−10, 10]。

### 2.5 帧编码与优化
- 采用 DCVC-DC 条件帧编解码器，以 {C^s_t} 为条件；×1/4 上下文为熵建模提供时序先验。
- 码率：`Rt = R(ŷ^m_t) + R(ẑ^m_t) + R(ŷt) + R(ẑt)`（运动/帧潜变量及其超先验，不含共享事件）。
- 损失：`L_RD,t = Rt + λ·D(Xt, X̂t)`。

### 2.6 合成 RGB–事件数据集构建（图 2）
1. **时间稠密化**：Super-SloMo 在相邻帧间插 F−1 帧，`F = ⌈f_target/f_src⌉`，f_target = 200 fps。
2. **强度序列**：转 8-bit 灰度并赋时间戳 `τi = i·⌊10^6/(F·f_src)⌉` 微秒（稠密帧仅用于事件合成）。
3. **事件模拟**：DVS-Voltmeter（DVS346 预设，无额外标定）。
4. **时间配对**：按原始帧时间戳切分，`E_{t-1:t} = {(x,y,τ,p) | T_{t-1} < τ ≤ Tt}`，每个编码区间关联 (Xt−1, E_{t−1:t}, Xt)。

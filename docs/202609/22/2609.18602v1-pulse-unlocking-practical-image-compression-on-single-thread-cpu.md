## 摘要
尽管学习型图像压缩最近取得了进展，现有方法在资源受限硬件（尤其是 CPU）上仍然计算开销高昂。我们提出 PULSE，一种实用编解码器，它能够：(1) 借助超低复杂度、5.2 kMAC/像素的神经接收器，在多种硬件平台上实现低延迟解码；(2) 通过整数线性 CDF 预测器和元先验实现高效的位精确熵编码。为了在这种严格预算下恢复压缩性能，我们引入一种由启发式探针引导的智能体进化过程，通过人类-LLM 协作迭代改进架构。PULSE 在单个 CPU 线程上以 126 ms 解码 1080p 图像，同时达到与 HM 相当的压缩性能。经过感知优化后，PULSE 可与 MS-ILLM 等更大的感知编解码器竞争。代码见 https://github.com/microsoft/GenCodec/tree/main/PULSE

## Abstract
Despite recent progress in learned image compression, existing methods remain computationally expensive on resource-constrained hardware, particularly CPUs. We introduce PULSE, a practical codec that enables (1) low-latency decoding on diverse hardware platforms with an ultra-low-complexity 5.2 kMAC/pixel neural receiver, and (2) efficient bit-exact entropy coding with an integer linear CDF predictor and a meta prior. To recover compression performance under this tight budget, we introduce an agentic evolution process guided by heuristic probes that iteratively improves the architecture through human-LLM collaboration. PULSE decodes a 1080p image in 126 ms on a single CPU thread while achieving compression performance comparable to HM. After perceptual optimization, PULSE competes with larger perceptual codecs like MS-ILLM. Codes are at https://github.com/microsoft/GenCodec/tree/main/PULSE

# PULSE 论文总结

## 1. 核心问题与研究背景

- **研究动机**：学习型图像压缩虽性能优异，但在资源受限硬件（尤其是 CPU）上计算开销极高，难以实际部署。
- **现状瓶颈**：
  - 早期端到端方案（Ballé 等）约需 80 kMAC/像素，后续为提升率失真性能将接收器复杂度推高至数百 kMAC/像素（ELIC、MLIC++ 等），即使在 GPU 上也难实时解码。
  - 实例自适应编解码器（Cool-Chic、C3）虽把接收器降到 5 kMAC/像素以下，却将大量计算转移到编码端逐图优化，且熵模型高度串行，效率低。
  - 高效端到端方案（EVC ~110 kMAC/像素、Shallow NTC ~20 kMAC/像素、DCVC-RT 实时 GPU）仍难以在 CPU 等边缘设备规模化部署。
- **PULSE 定位**：瞄准缺失的工作点——**超低复杂度、高度并行、端到端**的编解码器，发送端约 45 kMAC/像素、接收端仅 5.2 kMAC/像素，并以**单线程 CPU** 作为严苛部署压力测试。

## 2. 方法论

### 2.1 整体架构（非对称、可变码率、跨平台）

- 由**分析变换**、**两步熵模型**、**合成变换**组成，全部采用高并行算子，核心模块为深度卷积块（DCB）+ 通道注意力。
- **分析变换**：输入图像经 stride-16 patch embedding 得到 1/16 分辨率特征，接 4 个 DCB 和 1×1 投影得到主隐变量 y。
- **两步熵模型**：超编码器将 y 映射到 1/64 分辨率超隐变量 z，量化后由 Meta Prior 编码；超解码器恢复 h。采用棋盘格空间–通道划分将 y 分为互补掩码 m0、m1，第一步从 h 预测量化步长 q 与均值 μ0，第二步从 (h, ŷ0) 精化 μ1。中心化符号用离散零均值高斯建模，**尺度预测与非线性均值路径解耦**。
- **合成变换**：2 个 DCB 先做空间相关性建模；并行的内容分支将 ŷ 上采样 4 倍到 1/4 分辨率渲染网格，由低分辨率主干生成 AdaLN 调制参数 (α, β, γ)，经残差 pointwise MLP 后，每个网格向量投影为 4×4 RGB patch 并经 PixelShuffle 重排。

### 2.2 位精确线性 CDF 解码与 Meta Prior

- **问题**：浮点舍入误差会导致 CDF 表索引变化，使后续 rANS 符号全部失步；传统做法是整数化整个熵模型，但在超低复杂度预算下 CPU 开销大、量化损失明显。
- **线性 CDF 解码器**：不做完整的"ẑ→σ→logσ→CDF"链路，而是用**整数线性投影直接预测 CDF 索引**：
  - `Ĩ_CDF = W·ẑ + b_QP`，再 clip 到 [0, M−1] 取整得到 I_CDF；
  - 训练时把有界坐标映射为 `σ(Ĩ_CDF) = exp(log σ_min + Ĩ_CDF/M · (log σ_max − log σ_min))` 用于可微高斯似然评估；
  - 经验设置 σ_min=0.11、σ_max=256、M=64；
  - 推理时熵编码直接消费 I_CDF，**消除运行时指数/对数运算**。
- **Meta Prior**：线性 CDF 解码器把更多码率建模责任转移给 ẑ，而固定因子化先验无法适应不同内容复杂度。做法是主训练后将因子化先验**后训练扩展为 N=64 个先验库**，每个空间位置可自选先验并传输 log₂N 位索引：
  - `k*_r = argmin_k ℓ_{q,k}(ẑ_r)`，码率 `R_z = Σ_r [log₂N + ℓ_{q,k*_r}(ẑ_r)]`；
  - 用**硬 EM** 联合优化先验模型与位置级分配；
  - 低复杂度图像省 9.8% 码率，整体省 2.4%。

### 2.3 智能体进化（Agentic Evolution）

- 四阶段循环：**探针 → 分析 → 重分配 → 训练**，分析变换全程固定以隔离接收器设计。
- **启发式表示探针**：
  - **冗余探针（PCA 维度）**：拟合数据集共享 PCA 基，找使率失真损失增幅 ≤1% 的最小主成分数 C_PCA，比值 C_PCA/C_l 小说明通道冗余可回收；
  - **余量探针（隐变量优化）**：冻结下游参数、逐图优化 a_l，解码侧接口保持码率不变，测得 oracle PSNR 增益 G_OPT，大增益说明该接口需要更高容量。
- **人–LLM 协作分析**：LLM 接收探针结果、网络图、参数共享、组件 MAC 开销和历史轮次，提出 2–4 个固定预算候选；人类研究者审查可行性并选定训练候选。二者还可引入"**火花**"（spark）——超出预定义搜索空间的新机制或可调因子。
- **固定预算重分配与从零训练**：每个候选训练前先做复杂度 profiling，确保在固定预算内；同数据、码率范围、优化器和调度从零训练，最优者晋级。

### 2.4 感知与 ROI 优化

- **Stage I：LPIPS 优先预训练**，大幅提高 LPIPS 权重以建立细节合成能力；
- **Stage II：偏好优化**，降低 LPIPS 权重、引入 DINOv2 判别器的对抗训练、并加入 ROI 优化（对文字与人脸区域提高 MSE/LPIPS 权重并加入 FaceNet 与 CRNN 语义特征对齐）。

## 6. 主要结论与发现

- PULSE 在接收器仅 5.2 kMAC/像素下，单线程 CPU 解码 1080p 图像 **126 ms**，压缩性能与 HM-16.25 相当（CLIC Pro val 上 PSNR BD-rate −2.9%），编码速度快约 9 倍。
- PULSE-S 解码 77 ms（比 HEIC 更快），PSNR BD-rate +5.9%，远优于 HEIC 的 +25.2%。
- 感知优化后 PULSE 的 FID BD-rate 相对 MS-ILLM 为 −4.1%；

- 在感知指标上，PULSE 相对 MS-ILLM 的 FID BD-rate 为 −4.1%，并在 LPIPS-Alex、LPIPS-VGG、DISTS 上取得方向一致的 BD-rate 增益，说明感知质量的提升并非单一指标的偶然结果，而是跨指标稳定成立。
- **智能体进化的收益**：E1→E7 共 7 轮、22 次训练运行带来 10.2% 的 BD-rate 降低；作为对照，硬件感知 NAS 需约 1280 次训练才能达到相近量级。这表明在固定预算下，**"探针诊断 + 人–LLM 协作假设生成"** 比穷举式搜索更样本高效，且"火花"机制使搜索能跳出预定义空间、引入新的结构或可调因子。
- **消融结论**：解码器结构中，低分辨率解码器 + Renderer 的组合在同等 MAC 预算下最优；熵编码设计中，线性 CDF 解码器在保持位精确的同时避免整模型整数化带来的量化损失，Meta Prior 在此基础上进一步回收 2.4% 码率（低复杂度图像达 9.8%）；感知训练中高 LPIPS 预训练、对抗损失与 ROI 优化三者各自可分离地贡献增益。
- **跨设备位精确性**：在 Snapdragon 8 Elite NPU、Intel Core Ultra 9 288V CPU 与 A100 GPU 上，CDF 索引失配数与解码符号失配数均为 0，验证了线性 CDF 解码器在异构硬件上的可移植性。
- **整体定位**：PULSE 在"接收端复杂度—压缩性能"平面上给出了此前缺失的工作点——以约 HM 十分之一的编码耗时、可与 HM 相当的码率，以及远快于 HEIC 的解码速度，证明端到端神经编解码器可以进入单线程 CPU 可服务的部署区间。

## 7. 局限性与未来工作

- **基线可比性**：部分对比方法来自第三方重实现或公开重建结果（ELIC、MRIC、PICO 等），HiFiC 因缺少可用预训练模型改用官方 RD 数据，可能引入实现偏差，绝对 BD-rate 数值需谨慎解读。
- **任务范围**：方法面向**帧内图像压缩**，未涉及帧间预测或视频时序建模，向视频编解码扩展尚属开放问题。
- **感知评估的尺度**：FID 在 256×256 重叠 patch 上计算，虽提升了对局部纹理的敏感度，但仍不能完全替代全图主观评价，尤其在高分辨率细节与语义一致性上。
- **搜索流程的可复现性**：智能体进化依赖特定 LLM（gpt-5.6-sol，high reasoning effort）与人类研究者审查，搜索轨迹带有一定随机性与主观判断成分，跨团队复现成本较高。
- **部署压力测试的边界**：单线程 CPU 是刻意设置的严苛下限，论文未系统报告移动 NPU 上端到端（含 rANS 熵解码）的功耗与时延表现，实际边缘部署仍需针对性优化。

## 8. 主要贡献与启示

- **位精确线性 CDF 解码**：绕开"ẑ→σ→logσ→CDF"链路，直接用整数线性投影预测 CDF 索引，在消除运行时指数/对数运算的同时保证跨平台位精确，为低复杂度熵编码提供了可复用的工程范式。
- **Meta Prior**：以 N=64 先验库 + 位置级硬 EM 分配替代固定因子化先验，用 log₂N 位索引换取对内容复杂度的自适应，是低开销下提升熵模型表达力的有效手段。
- **智能体进化工作流**：把"冗余探针/余量探针"作为可解释诊断信号，交由 LLM 提出固定预算候选、人类把关，再从零训练择优，形成一套**样本高效、可归因**的架构搜索协议。
- **非对称编解码设计**：发送端 45 kMAC/像素、接收端 5.2 kMAC/像素的强不对称分配，配合 stride-16 patch embedding 与 Renderer 式合成变换，说明在解码侧极度受限时，把复杂度前移到编码端是可行的工程取舍。
- **感知与 ROI 的两阶段训练**：先以高 LPIPS 权重建立细节合成能力，再以对抗损失 + ROI 加权（文字、人脸，辅以 FaceNet/CRNN 语义对齐）精修，兼顾了整体感知质量与关键区域可用性。

## 摘要
在基于条件编码的神经视频压缩中，时间上下文的质量直接影响压缩性能。现有方法大多从传播的参考特征中构建上下文，但在复杂运动、遮挡和高频纹理区域，它们容易受到运动估计和局部对齐误差的影响，导致时间信息不准确。为解决这一问题，本文提出了一种结合可变形时间对齐与差异感知空间选择性融合的方法。使用上下文感知的时间对齐模块生成互补的时间上下文，而差异感知的空间选择性融合模块则自适应地选择可靠的时间信息并抑制错位。实验表明，所提方法相比DCVC-DC在率失真性能上取得了一定提升。

## Abstract
In conditional coding-based neural video compression, the quality of temporal context directly affects compression per- formance. Existing methods mostly construct context from prop- agated reference features, but they are vulnerable to motion esti- mation and local alignment errors in regions with complex mo- tion, occlusion, and high-frequency textures, resulting in inaccu- rate temporal information. To address this issue, this paper pro- poses a method combining deformable temporal alignment and difference-aware spatial selective fusion. A Context-aware Tem- poral Alignment Module is used to generate complementary tem- poral context, while a Difference-aware Spatial Selective Fusion module adaptively selects reliable temporal information and sup- presses misalignment. Experiments show that the proposed method achieves certain rate-distortion performance improve- ment over DCVC-DC.

## 详细中文总结

### 一、核心问题与研究动机

- **问题背景**：在条件编码（conditional coding）的神经视频压缩（NVC）框架中，时间上下文（temporal context）是当前帧编码与解码的关键先验，其质量直接决定压缩效率与重建质量。
- **现有缺陷**：以 DCVC-DC 为代表的方法主要依赖**传播参考特征**与解码运动信息来构建时间上下文，但在长预测链、复杂运动、遮挡和高频纹理区域中，参考特征会随时间累积与当前帧弱相关的信息；同时，压缩后的运动信息本身也会引入局部对齐误差，导致生成的时间上下文不够准确，最终影响压缩性能。
- **研究目标**：在**不改变运动编码流程与码流结构**的前提下，增强时间上下文的准确性与可靠性，提升率失真性能。

### 二、方法论

#### 核心思想
通过两条互补路径生成时间上下文，并设计自适应融合机制：
1. 一条路径沿用 DCVC-DC 原有框架，生成**传播上下文**；
2. 另一条路径为新增的 **CTAM**，利用相邻重建帧构造**可变形对齐上下文**；
3. 用 **DSSF** 依据上下文差异图自适应融合两路信息，抑制局部错位。

#### 关键技术细节

**1. 上下文感知时间对齐模块（CTAM）**
- 先利用解码运动表示 $\hat{v}_t$ 对参考帧 $\hat{x}_{t-1}$ 做反向扭曲（backward warping），得到预测帧 $\tilde{x}_t$；
- 通过轻量特征提取分支分别提取参考帧与预测帧的特征，在特征域融合后送入可变形对齐网络；
- 可变形卷积预测空间采样偏移 $\Delta p$：

$$\Delta p = f_{\psi}([g(\hat{x}_{t-1}), g(\tilde{x}_t)])$$

$$\hat{X}^{(l)}(p_0) = \sum_{p_k \in R} w(p_k) X^{(l-1)}(p_0 + p_k + \Delta p_k^{(l)}(p_0))$$

- 通过多级可变形卷积逐步精化对齐结果，生成**可变形对齐时间上下文** $\check{C}_t^0$，以捕捉复杂运动、非刚性形变与遮挡对应的特征域关联。

**2. 差异感知空间选择性融合模块（DSSF）**
- 计算两路上下文的差异图：

$$D_t = |C_t^0 - \check{C}_t^0|$$

- 将传播上下文 $C_t^0$、可变形对齐上下文 $\check{C}_t^0$ 与差异图 $D_t$ 共同送入轻量融合网络，产生空间选择权重：

$$[A_b, A_c] = S(C_t^0, \check{C}_t^0, D_t)$$

- 加权融合得到**补偿上下文**：

$$\bar{C}_t^0 = A_b \odot C_t^0 + A_c \odot \check{C}_t^0$$

- 设计动机：不同空间区域两种上下文的可靠性不同（例如大运动/遮挡区域更依赖可变形对齐的局部特征，平坦/小运动区域更适合稳定的传播特征），DSSF 通过空间权重实现逐位置的自适应选择。

**架构影响**：两个新增模块仅改变时间上下文构建路径，不涉及运动估计/编码的改动，不增加码流开销。

### 六、主要结论

- 在 DCVC-DC 基线之上同时引入 CTAM 与 DSSF，可将平均 BD-Rate 从 −17.3% 进一步降至 −19.0%（相对 DCVC-DC 平均节省约 1.9% 的码率），同时保持重建质量提升；

  - 完整方法（CTAM + DSSF）为 1.9%，验证了差异感知选择性融合相对于直接拼接的优越性。

1. **针对性强**：准确定位了条件编码 NVC 中传播参考特征的脆弱性——在复杂运动、遮挡、高频纹理区域易产生对齐错误；
2. **模块化设计**：CTAM 与 DSSF 均为即插即用模块，不改动运动编码路径，不增加码流，兼容现有 DCVC 系框架；
3. **思路互补**：传播上下文与基于相邻重建帧的可变形对齐上下文各有优势，DSSF 通过差异图引导加权融合，比简单拼接更精细，具备空间自适应能力；
4. **工程成本低**：CTAM 使用轻量特征提取分支和可变形卷积，DSSF 为轻量融合网络，整体结构相对简洁；
5. **实验设置规范**：测试配置（96 帧、intra-period=32、RGB/PSNR 评测）与领域主流方法保持一致，对比公平。

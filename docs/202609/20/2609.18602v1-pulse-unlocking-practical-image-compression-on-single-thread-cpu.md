## 摘要
尽管基于学习的图像压缩近来取得了进展，现有方法在资源受限硬件（尤其是 CPU）上仍然计算开销高昂。我们提出 PULSE，一种实用编解码器，它支持：(1) 在多种硬件平台上以超低复杂度 5.2 kMAC/像素的神经接收器实现低延迟解码；(2) 借助整数线性 CDF 预测器和元先验实现高效的位精确熵编码。为了在如此紧张的预算下恢复压缩性能，我们引入一种由启发式探针引导的智能体进化过程，通过人类-LLM 协作迭代改进架构。PULSE 在单个 CPU 线程上以 126 毫秒解码 1080p 图像，同时达到与 HM 相当的压缩性能。经过感知优化后，PULSE 可与 MS-ILLM 等更大的感知编解码器竞争。代码见 https://github.com/microsoft/GenCodec/tree/main/PULSE

## Abstract
Despite recent progress in learned image compression, existing methods remain computationally expensive on resource-constrained hardware, particularly CPUs. We introduce PULSE, a practical codec that enables (1) low-latency decoding on diverse hardware platforms with an ultra-low-complexity 5.2 kMAC/pixel neural receiver, and (2) efficient bit-exact entropy coding with an integer linear CDF predictor and a meta prior. To recover compression performance under this tight budget, we introduce an agentic evolution process guided by heuristic probes that iteratively improves the architecture through human-LLM collaboration. PULSE decodes a 1080p image in 126 ms on a single CPU thread while achieving compression performance comparable to HM. After perceptual optimization, PULSE competes with larger perceptual codecs like MS-ILLM. Codes are at https://github.com/microsoft/GenCodec/tree/main/PULSE

## 1. 核心问题与研究动机

- **背景**：基于学习的图像压缩（LIC）在率失真性能上持续进步，但代价是神经接收器复杂度不断膨胀。
  - 早期端到端方案（Ballé 等）约需 **80 kMAC/像素**；
  - 后续提升率失真的工作将接收器复杂度推高到 **数百 kMAC/像素**，即便在 GPU 上也难以实时解码。
- **现有折中路径的两难**：
  - **实例自适应编解码器**（Cool-Chic、C3）把复杂度降到 <5 kMAC/像素，却把大量计算转移到**编码阶段的逐图优化**，且熵模型高度串行，实现效率低；
  - **高效端到端方案**（EVC ~110、Shallow NTC ~20 kMAC/像素、DCVC-RT 面向 GPU 实时）在资源受限的边缘设备（尤其是 **CPU**）上仍难以规模化部署。
- **目标操作点**：PULSE 瞄准一个被忽视的区间——**超低复杂度、高并行、端到端**，发送端约 **45 kMAC/像素**、接收端仅 **5.2 kMAC/像素**，以**单线程 CPU** 作为严苛的部署压力测试，同时保持有界趟数的熵依赖与对加速器友好的算子。
- **要解决的三个核心问题**：
  1. 在超低复杂度预算下如何设计编解码器架构？
  2. 如何在最小损失下实现跨设备**位精确（bit-exact）熵编码**？
  3. 如何有效提升感知质量？

## 2. 方法论

### 2.1 整体架构（非对称、变码率、跨平台）

- **分析变换（编码器）**：输入图像经 stride-16 patch embedding 降到 1/16 分辨率，接 4 个深度卷积块（DCB，含通道注意力）与 1×1 投影，得到主潜变量 `y`。
- **两步熵模型**：超先验编码器把 `y` 映射到 1/64 分辨率的超潜变量 `z`；量化后的 `ẑ` 由 **QP 条件化的 Meta Prior** 编码，超先验解码器恢复出 `h`。借鉴 DCVC-HEM 的双空间先验，用空间-通道棋盘掩码把 `y` 分成互补的 `m0`、`m1`：
  - 第一步从 `h` 预测量化步长 `q` 与均值 `μ0`；
  - 第二步从 `(h, ŷ0)` 精化 `μ1`；
  - 中心化符号 `yqi = round(y/q − μi) ⊙ mi`，用离散零均值高斯建模。
  - **关键设计**：尺度预测与非线性均值路径**解耦**——一条投影把 `ẑ` 直接映射到共享高斯 CDF 表中的连续坐标，两趟复用同一尺度坐标，仅 `μi` 不同。
- **合成变换（解码器）**：两路并行——两个 DCB 处理 `ŷ` 建模空间相关性；内容分支把 `ŷ` 上采样 4 倍到 1/4 分辨率渲染网格，低分辨率主体生成 AdaLN 调制参数 `(α, β, γ)` 驱动残差逐点 MLP，最后每格投影为 4×4 RGB patch 并经 PixelShuffle 重排。

### 2.2 位精确线性 CDF 解码 + Meta Prior

- **问题**：平台相关的浮点舍入一旦改变 CDF 表索引，会令后续所有 rANS 符号失同步。传统做法是把**整个熵模型整数化**，但在超低复杂度预算下带来明显 CPU 开销与量化损失。
- **线性尺度解码器的启发**：只用 LUT 从 `ẑ` 推尺度虽极快（0.5 ms）但率失真损失巨大（+29.7%）；仅整数化超尺度解码器（JPEG AI 式）损失小但耗时 28.1 ms。作者发现**从 `ẑ` 到尺度的简单线性投影**是有效折中（INT8 下仅 ~1.5% BD-rate 损失，CPU 时间 28.1 → 1.2 ms），但存在两个缺陷：`σ→log σ` 路径仍需 INT8 执行（+2.9 ms）；且高斯 CDF 索引在对数尺度上均匀分布，导致**尺度相关的索引敏感度**。
- **线性 CDF 解码器（核心创新）**：不做尺度预测，而是**直接预测 CDF 索引**。
  - 线性投影给出连续坐标：`Ĩ_CDF = W ẑ + b_QP`，再 clip 并取整为整数索引 `I_CDF ∈ {0,…,M−1}`；`b_QP` 为可学习的逐 QP 偏置。
  - 训练时把有界坐标映射为 `σ(Ĩ_CDF) = exp(log σ_min + Ĩ_CDF/M · (log σ_max − log σ_min))` 用于可微高斯似然评估；经验取 `σ_min=0.11`、`σ_max=256`、`M=64`。
  - 推理时熵编码直接消费 `I_CDF`，**消除运行时的指数与对数运算**，CPU 时间降到 **1.6 ms**，且 BD-rate 优于 INT8 超尺度解码器。
- **Meta Prior（元先验）**：线性 CDF 解码器把更多率建模责任推给 `ẑ`，而固定因子化先验无法适应内容差异（低复杂度图像中 `ẑ` 约占一半码流）。
  - 主训练后，把因子化先验**后训练**为一个含 `N` 个先验模型的先验库，各先验拟合不同内容复杂度区域的超潜向量，其他模块冻结。
  - 用 **EM 过程**联合优化先验模型与其位置级分配；推理时每个空间位置 `r` 选取编码代价最小的先验库索引 `k*_r`，码流中每个位置共享一个 `log2 N` 比特索引作为元信息，解码端据此选固定 CDF 库解码 `ẑr`，**无需额外神经网络推理**。
  - 效果：低复杂度图像省 9.8% 码率，整体省 2.4%。
  - 部署细节：线性 CDF 的激活与权重为 INT8、累加 INT32、输出 UINT8 索引；Meta Prior 库索引用定长编码（可用合并编码进一步改进）。

### 2.3 启发式探针驱动的智能体进化（Agentic Evolution）

- **动机**：超低复杂度下每个通道和算子都至关重要，参数/算子分配直接决定性能；PICO 式 NAS 需搜索数百万架构、训练代价高且依赖静态预定义网络。
- **四阶段循环：probe → analyze → reallocate → train**（分析变换固定，只进化接收器）：
  - **冗余探针（PCA 维度）**：拟合数据集共享 PCA 基，找出使率失真损失增量 ≤1% 的最小主成分维数 `C_PCA`，比值 `C_PCA/C_l` 小意味着通道冗余可回收。
  - **余量探针（潜变量优化）**：冻结下游参数、逐图优化该层潜变量，解码端接口在码率不变下测 oracle PSNR 增益 `G_OPT`，增益大说明该接口需要更大容量。
  - **人-LLM 协作分析**：LLM（gpt-5.6-sol，高推理强度）接收探针结果、网络图、参数共享、组件 MAC 开销与历史，提出固定预算改动；人类研究者审核假设、可行性与预算核算后选定候选。双方都可引入 **"spark"**（新的架构机制或可调因子），使搜索空间本身随新瓶颈演化。
  - **固定预算重分配 + 从头训练**：先 profiling 确保复杂度预算内，再以相同数据/码率范围/优化器/调度从头训练，取最优者晋级。
- **成果**：仅 **7 轮进化、22 次训练**，最终 E7 相对 E1 取得 **10.2% BD-rate 下降**；对比硬件感知 NAS（1280 次训练，-7.5%）。
- **缩放**：把通道调为 16 的倍数得 PULSE-S，再扩通道得 5.2 kMAC/像素的 PULSE 与 20 kMAC/像素的 PULSE-L。

### 2.4 感知与感兴趣区域（ROI）优化

- **Stage I：LPIPS 优先的感知预训练**——显著加大 LPIPS 权重（`φ_I_LPIPS` 远高于以往工作），建立细节合成能力。
- **Stage II：偏好优化**——(1) 回调 LPIPS 权重以抑制伪影；(2) 引入基于 **DINOv2 判别器**的对抗训练（从 ViT-B/14 第 3/6/9/12 块提取特征，hinge 判别损失）实现分布级对齐；(3) 引入 **ROI 优化**，对文本/人脸密集区域加大 MSE 与 LPIPS 权重，并加入语义特征对齐（FaceNet 人脸、CRNN-CNN 文本教师）。

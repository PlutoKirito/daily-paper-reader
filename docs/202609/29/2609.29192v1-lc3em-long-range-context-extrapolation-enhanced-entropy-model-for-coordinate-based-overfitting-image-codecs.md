## 摘要
基于坐标的过拟合图像编解码器因其低解码复杂度以及不依赖跨图像泛化而受到越来越多关注。然而，诸如 COOL-CHIC 之类的代表性方法面临固有的熵建模权衡：轻量模型容量有限，而表达能力更强的模型则因传输图像特定参数而带来额外码率开销。受传统编解码器中预测机制的启发，我们提出一种新的熵建模策略，引入互补预测模式以及区域自适应软模式选择，而不是依赖单个学习到的预测器来建模多种类型的冗余。基于这一概念，我们提出了长程上下文外推增强熵模型（LC3EM），该模型可集成到基于坐标的过拟合编解码器中。具体而言，一种无参数的基于邻域的线性外推模式（NLEM）与基于微型 MLP 的局部预测器互补，以利用长程上下文冗余和强方向性结构。设计了一种受最小熵启发的连续模式选择策略，以自适应融合这两种互补模式，同时仅需传输一个额外线性层的参数。此外，为缓解训练时松弛量化与实际离散量化之间的不匹配，我们引入轻量级迭代隐变量舍入细化阶段，以提高压缩性能。实验表明，在不同基准上均有一致性提升，尤其是在高度规则的计算机生成图像上。与 COOL-CHIC 4.0 集成时，所提方法在 SIQAD 和 API 数据集上分别取得 -3.43% 和 -7.69% 的 BD-rate 增益。以 COOL-CHIC 5.0 作为骨干时，相应增益分别为 -2.88% 和 -3.15%。代码即将公开。

## Abstract
Coordinate-based overfitting image codecs have attracted increasing attention for their low decoding complexity and independence from cross-image generalization. However, representative approaches such as COOL-CHIC face an inherent entropy-modeling trade-off: lightweight models have limited capacity, while more expressive ones incur additional bitrate overhead from transmitting image-specific parameters. Inspired by the prediction mechanism in traditional codecs, we propose a new entropy-modeling strategy that introduces complementary prediction modes with region-adaptive soft mode selection, rather than relying on a single learned predictor to model diverse types of redundancy. Based on this concept, we develop a Long-Range Context Extrapolation Enhanced Entropy Model (LC3EM), which can be integrated into coordinate-based overfitting codecs. Specifically, a parameter-free Neighborhood-based Linear Extrapolation Mode (NLEM) complements the tiny MLP-based local predictor to exploit long-range contextual redundancy and strongly directional structures. A Minimum-Entropy-Inspired Continuous Mode Selection strategy is designed to adaptively fuse these two complementary modes, while requiring the transmission of only the parameters of a single additional linear layer. Moreover, to alleviate the mismatch between training-time relaxed and actual discrete quantization, we introduce a lightweight iterative latent rounding refinement stage to improve compression performance. Experiments demonstrate consistent improvements across diverse benchmarks, particularly on highly regular computer-generated images. When integrated with COOL-CHIC 4.0, the proposed method achieves BD-rate gains of -3.43\% and -7.69\% on the SIQAD and API datasets, respectively. With COOL-CHIC 5.0 as the backbone, the corresponding gains are -2.88\% and -3.15\%, respectively. The code will be made publicly available soon.

## 1. 核心问题与研究动机

- **背景**：基于坐标的过拟合图像编解码器（以 COOL-CHIC 系列为代表）因**低解码复杂度**和**不依赖跨图像泛化**而受到关注，其 RD 性能已从早期仅优于 JPEG 发展到与 H.266/VVC 竞争，甚至媲美先进自编码器方法。
- **核心矛盾**：该框架的熵模型面临一个固有权衡——
  - 轻量模型容量有限，难以捕捉**长程上下文信息**，无法充分利用隐变量网格中的冗余；
  - 增强模型容量则必须将网络参数一并编码传输，直接带来**额外码率开销**。
- **关键洞察**：传统编解码器（如 H.266/VVC 的 67 种帧内预测模式）通过**互补预测模式 + RDO 模式选择 + 仅传输模式索引**实现内容自适应预测且开销可忽略。受此启发，论文试图回答：*能否以可忽略的参数传输开销增强熵模型能力？*

## 2. 方法论

### 2.1 核心思想
在 COOL-CHIC 的微型 MLP 局部预测器之外，引入一个**无参数手工预测模式（NLEM）**，并通过**分布级软融合（MECMS）** 实现区域自适应选择，仅需额外传输一个线性层参数。

### 2.2 邻域线性外推模式（NLEM）
- **目标**：对隐变量位置 p，用已解码邻域特征进行线性外推预测 Î(p) = xₚᵀa。
- **三步流程**：
  1. **长程上下文样本构建**：采集 s 个已解码上下文位置，构成观测矩阵 X ∈ ℝˢˣᶜ 和观测向量 y；通过模板匹配计算相似度得分 Sₖ = exp(−‖t(qₖ)−t(p)‖²/(2dₜρ²))，形成对角相似度矩阵 S（ρ=0.1，Sₖ 裁剪至 [10⁻³, 1]）。论文取 s=40、c=4，使 NLEM 可利用比 MLP（≤20 个上下文）更全局的上下文。
  2. **外推系数估计**：加权最小二乘 + 岭正则化，即求解 (XᵀSX + ηI)a = XᵀSy，其中 η = ε·(1/c)tr(XᵀSX) 自适应确定（ε=0.01）。
  3. **特征预测**：Î(p) = xₚᵀa*，实际实现中还估计并纳入常数项 a₀。
- **特点**：**无参数传输**，擅长建模边缘、线状纹理等强方向性长程冗余。

### 2.3 最小熵启发的连续模式选择（MECMS）
- **动机**：逐点熵建模使逐隐变量模式索引传输不可行，硬选择不可微，无法端到端训练。
- **理论推导**：在随机变量域考虑融合 Z* = wZ₁+(1−w)Z₂；假设两预测近似不相关，方差为 w²σ₁²+(1−w)²σ₂²，最小化得最优权重 w* = σ₂²/(σ₁²+σ₂²)，且 (σ*)² = w*σ₁² = (1−w*)σ₂²——**融合权重同时控制均值插值与尺度缩减**。
- **实用参数化**：
  - 均值 μ* = wμ₁ + (1−w)μ₂；
  - 尺度 (b*)² = w·b₁²（w∈[0,1] 时）；
  - 融合权重由一个**单层全连接 + tanh** 的轻量网络预测：w = (1.5·tanh(g_w(h)))_+，仅增加一个线性层参数。
- **外推扩展**：w 范围从 [0,1] 扩展到 [0,1.5]；当 w∈(1,1.5] 时均值更新不变，尺度改为 (b*)² = (2w²−2w+1)b₁²，允许在难以有效融合时**增大尺度参数**以避免性能下降。w 下界设为 10⁻⁸ 防止尺度退化。

### 2.4 迭代隐变量舍入细化
- **问题**：训练用噪声松弛近似量化，实际编码用确定性舍入，二者失配；NLEM 从前序已解码隐变量估计系数，对扰动尤其敏感。
- **方案**：冻结全部网络参数，仅更新隐变量网格，采用双类 SGA（随机 Gumbel 退火）+ SSL（sigmoid 缩放 logit）松弛：
  - 对每个隐变量定义下取整/上取整两个候选 I⁻、I⁺ 及距离 d⁻、d⁺；
  - 候选得分 ℓ_r(p) = −log[1+(d_r/(1−d_r))^α]，α=1.2；
  - 加入 Gumbel 噪声后经温度 T 的 softmax 得到软分配概率 π_r；
  - 松弛隐变量 Ĩ(p) = π₋I⁻ + π₊I⁺；
  - **两阶段码率估计**：前 1/4 迭代直接在松弛值上评估码率，后续改用两个整数候选的期望编码代价。
- **配置**：每步 3 次独立采样近似期望，2000 次 Adam 更新（仅占额外 2% 迭代），T 从 0.3 几何退火至 0.08，学习率从 5×10⁻⁴ 余弦退火至 1×10⁻⁵，最终硬舍入编码。

- **范式迁移价值**：将传统视频/图像编解码器中的“多假设预测 + RDO 模式选择 + 低开销索引传输”思想迁移到过拟合神经编解码器，证明手工先验与轻量可学习融合可以互补，而不必一味扩大网络容量。
- **“无参数模式”思路**：NLEM 不传输任何模式参数，仅依赖已解码邻域与模板匹配，为低码率场景下增强熵模型提供了新路径。
- **分布级软融合**：MECMS 不传输硬模式索引，而是让网络预测融合权重，并联合调整均值与尺度，为逐点自适应熵建模提供了可微、低开销的实现方式。
- **量化一致性训练**：迭代隐变量舍入细化针对训练—推理失配问题，对任何依赖量化隐变量的过拟合编解码器都具有借鉴意义。
- **内容自适应增益**：结果提示，面向屏幕内容、动漫等计算机生成图像时，长程方向性结构与重复纹理更显著，所提方法收益更大，这对专用编解码器设计具有指导意义。

## 10. 总体评价

LC3EM 是一篇动机清晰、方法紧凑、实验较扎实的论文。它没有通过扩大网络规模来提升熵模型，而是从传统编解码器的多模式预测中汲取灵感，用零参数传输的 NLEM 和仅增加一个线性层的 MECMS，在极低码率开销下实现了内容自适应的预测融合。理论推导、消融实验、码流构成分析和复杂度剪枝共同支撑了其核心主张：**增强熵模型能力不必以显著增加参数码率为代价**。主要不足在于实际解码复杂度与硬件开销报告不足、自然图像增益有限、部分理论假设理想化，以及 COOL-CHIC 5.0 上缺少组件级消融。总体而言，该方法在过拟合图像编解码方向具有较好的创新性与实用潜力，尤其适合屏幕内容与动漫类图像的低码率压缩。

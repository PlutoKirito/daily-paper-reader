## 摘要
视频压缩旨在在受限比特率下最小化重建失真。现有的视频隐式神经表示（INRs）通常独立解码各帧，使中间特征未以先前重建为条件，且内容嵌入缺乏显式时序预测。我们提出 TCNeRV，它在特征域和嵌入域中均利用重建上下文。其多尺度时序上下文融合（MTCF）模块在多个解码器尺度注入门控历史特征，而时序嵌入残差编码（TERC）预测每个内容嵌入并仅编码其残差。TCNeRV 参数量约为 3M，在 UVG 数据集上达到 36.08 dB 的平均 PSNR，比 HNeRV-Boost 高出 2.20 dB。相对于 HM、DCVC 和 HiNeRV，它分别将 BD-rate 降低 22.06%、66.73% 和 29.85%，表明在有限模型容量下具有竞争力的率失真性能。

## Abstract
Video compression aims to minimize reconstruction distor tion under a constrained bit rate. Existing video implicit neural representations (INRs) often decode frames independently, leaving intermediate features unconditioned on previous reconstructions and content embeddings without explicit temporal prediction. We propose TCNeRV, which exploits reconstructed context in both feature and embedding domains. Its multi-scale temporal-context fusion (MTCF) module injects gated historical features at multiple decoder scales, while temporal embedding-residual coding (TERC) predicts each content embedding and codes only its residual. With approximately 3M parameters, TCNeRV achieves an average PSNR of 36.08 dB on the UVG dataset, outperforming HNeRV-Boost by 2.20 dB. It reduces BD-rate by 22.06%, 66.73%, and 29.85% relative to HM, DCVC, and HiNeRV, respectively, demonstrating competitive rate-distortion performance with limited model capacity.

## 1. 核心问题与整体含义

- **研究背景**：视频压缩的核心目标是在受限码率下最小化重建失真。传统标准（HEVC、VVC）依赖块划分、预测、变换量化与熵编码；学习式编解码器（DVC、DCVC、DCVC-DC 等）虽联合优化多个模块，但通常包含运动、上下文、残差与熵模型等多个子网络，复杂度较高。
- **隐式神经表示（INR）路线**：NeRV、E-NeRV、HNeRV、HiNeRV、HNeRV-Boost 等将视频帧表示为坐标/索引条件网络的输出，具有紧凑、端到端可微等优势。
- **核心问题**：现有视频 INR 大多**独立解码各帧**，导致：
  - 解码器中间特征没有以历史重建为条件，无法复用前帧结构与纹理；
  - 帧级内容嵌入独立编码，量化前未去除时间上可预测的信息，时间冗余利用不足。
- **整体含义**：论文提出 **TCNeRV**，在**特征域**与**嵌入域**同时建模时序上下文，以轻量模型实现更具竞争力的率失真性能，属于“隐式神经视频压缩 + 时序预测编码”交叉方向。

## 2. 方法论

### 2.1 核心思想

- 基于 **HNeRV-Boost** 框架，使用量化后的内容嵌入、时间嵌入与条件解码器参数表示视频。
- 利用**前一帧重建结果**构造因果时序上下文，并在两个域中加以利用：
  - **特征域**：MTCF 将历史重建特征注入多尺度解码器；
  - **嵌入域**：TERC 预测当前内容嵌入，仅编码预测残差。
- 编码器与解码器共享同一因果闭环：第一帧使用零上下文，后续帧使用前一重建。

### 2.2 多尺度时序上下文融合（MTCF）

- 在解码器 **Stage 3 与 Stage 4** 两个尺度上操作，分辨率分别为 \(135 \times 240\) 与 \(270 \times 480\)。
- 将前一重建 \(c_t\) 双线性缩放至对应尺度，并经变换 \(\Phi_i\) 得到上下文特征：
  - \(\Phi_i\) 包含 \(3\times3\) 卷积、GELU 激活、\(1\times1\) 卷积；
  - 通道映射为 \(3 \rightarrow \max(C_i,32) \rightarrow C_i\)。
- 使用可学习门控进行通道级融合：
  - \(a_i = \text{sigmoid}(g_i)\)；
  - \(f^{out}_i = f^{dec}_i + a_i \odot f^{ctx}_i\)。
- 设计含义：
  - Stage 3 提供布局与运动线索；
  - Stage 4 增强边缘与纹理；
  - 门控可抑制遮挡、快速运动或场景变化下不可靠的历史信息；
  - 不改变主干结构，无需显式运动估计。

### 2.3 时序嵌入残差编码（TERC）

- 共享 ConvNeXt 编码器提取目标嵌入 \(y_t = E(x_t;\phi)\)，嵌入尺寸为 \(C_e=16\)、\(H_e\times W_e=9\times16\)。
- 当前嵌入预测：
  - \(t=0\) 时，\(y^{pred}_t=0\)；
  - \(t\ge1\) 时，\(y^{pred}_t = P(\text{stopgrad}[E(c_t;\phi)])\)，其中 \(P\) 为 \(1\times1\) 卷积预测器。
- 仅对残差 \(r_t = y_t - y^{pred}_t\) 进行量化与熵编码。
- 解码端重建嵌入：
  - \(\hat{y}_t = \text{stopgrad}(y^{pred}_t) + \hat{r}_t\)。
- 关键机制：
  - 第一帧编码完整嵌入，后续帧只编码时间上不可预测的信息；
  - **stop-gradient** 防止预测分支与残差分支相互抵消；
  - 训练损失、熵正则与压缩微调遵循 HNeRV-Boost。

  - 约 3M 参数下，TCNeRV 在 UVG 上平均 PSNR 达 **36.08 dB**；
  - 比 HNeRV-Boost 高 **2.20 dB**，比 HiNeRV 高 **0.82 dB**；
  - 在中等和较大模型规模下，相对 HNeRV-Boost 分别提升 **1.70 dB** 和 **1.11 dB**；
  - 高运动序列提升更明显，说明历史上下文有效。
- **压缩性能**：
  - 相对 HM、DCVC、DCVC-HEM、HNeRV-Boost、HiNeRV 的 BD-rate 分别降低：

    - DCVC：**66.73%**
    - DCVC-HEM：**24.10%**

    - HiNeRV：**29.85%**

- **消融结论**：

  - 主要增益来自 MTCF，TERC 提供额外但较小的改进。

## 7. 优点

- **双域时序建模**：同时在解码特征域和内容嵌入域利用历史重建，思路清晰，互补性强。
- **无需显式运动估计**：MTCF 通过多尺度特征对齐与门控融合实现时序上下文注入，避免复杂光流或运动分支。
- **轻量高效**：约 3M 参数、131G MACs，与 HNeRV-Boost 相当，但 PSNR 与 BD-rate 明显更优。
- **因果闭环设计**：编码端与解码端共享前一重建上下文，符合视频预测编码范式。
- **门控机制合理**：可抑制遮挡、快速运动、场景变化下不可靠的历史信息，提升鲁棒性。
- **残差编码先于量化**：TERC 在量化前去除时间可预测信息，直接作用于比特流，具有明确压缩意义。
- **消融验证清晰**：分别验证 MTCF 与 TERC 的贡献，表明 MTCF 是主要增益来源。

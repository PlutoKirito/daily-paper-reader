## 摘要
尽管基于学习的图像压缩最近取得了进展，现有方法在资源受限的硬件上，尤其是 CPU 上，计算开销仍然很高。我们提出 PULSE，一种实用编解码器，它能够：(1) 借助超低复杂度的 5.2 kMAC/像素神经接收器，在多种硬件平台上实现低延迟解码；(2) 通过整数线性 CDF 预测器和元先验实现高效的位精确熵编码。为了在这种严格预算下恢复压缩性能，我们引入了一种由启发式探针引导的智能体进化过程，通过人类与 LLM 协作迭代改进架构。PULSE 在单个 CPU 线程上以 126 ms 解码一张 1080p 图像，同时达到与 HM 相当的压缩性能。经过感知优化后，PULSE 可与 MS-ILLM 等更大规模的感知编解码器竞争。代码见 https://github.com/microsoft/GenCodec/tree/main/PULSE

## Abstract
Despite recent progress in learned image compression, existing methods remain computationally expensive on resource-constrained hardware, particularly CPUs. We introduce PULSE, a practical codec that enables (1) low-latency decoding on diverse hardware platforms with an ultra-low-complexity 5.2 kMAC/pixel neural receiver, and (2) efficient bit-exact entropy coding with an integer linear CDF predictor and a meta prior. To recover compression performance under this tight budget, we introduce an agentic evolution process guided by heuristic probes that iteratively improves the architecture through human-LLM collaboration. PULSE decodes a 1080p image in 126 ms on a single CPU thread while achieving compression performance comparable to HM. After perceptual optimization, PULSE competes with larger perceptual codecs like MS-ILLM. Codes are at https://github.com/microsoft/GenCodec/tree/main/PULSE

# PULSE 论文结构化总结

## 1. 核心问题与研究动机

- **背景**：学习式图像压缩（Learned Image Compression）在率失真性能上已显著超越传统编码，但主流方法的神经接收器（decoder）复杂度极高——早期方法约需 80 kMAC/pixel，后续高性能方法更是扩展到数百 kMAC/pixel，即便在 GPU 上也难以实时解码。
- **部署鸿沟**：为降低解码复杂度，已有两条路线：
  - **实例自适应编解码器**（如 Cool-Chic、C3）：将接收器压到 5 kMAC/pixel 以下，但把大量计算转移到编码阶段的逐图优化，且高度串行的熵模型不利于实现效率。
  - **高效端到端编解码器**（如 EVC、Shallow NTC、DCVC-RT）：分别将接收器降至约 110、20 kMAC/pixel，或实现 GPU 实时，但在 CPU 等资源受限边缘设备上仍难落地。
- **核心目标**：PULSE 瞄准一个“缺失的工作点”——**超低复杂度、高并行、端到端的编解码器**，发送端约 45 kMAC/pixel，接收端仅约 5.2 kMAC/pixel；以**单线程 CPU 作为最严苛的部署压力测试**，同时保留有限遍数的熵依赖和加速器友好算子，以便同一模型也能受益于 NPU/GPU。
- **三个核心问题**：
  1. 如何在超低复杂度预算下设计编解码器？
  2. 如何以最小损失实现跨设备位精确（bit-exact）熵编码？
  3. 如何有效提升感知质量？

## 2. 方法论

### 2.1 整体架构（非对称、可变码率、跨平台）

- **分析变换（编码器）**：输入图像经 stride-16 patch embedding 得到 1/16 分辨率特征，接 4 个深度卷积块（DCB，含通道注意力），再经 1×1 投影得到主潜变量 \(y\)。
- **两步熵模型**：超编码器将 \(y\) 映射为 1/64 分辨率的超潜变量 \(z\)；量化后的 \(\hat z\) 经 **Meta Prior** 编码，超解码器恢复 \(h\)。采用空间–通道棋盘格将 \(y\) 分为互补掩码 \(m_0, m_1\)：第一步从 \(h\) 预测量化步长 \(q\) 与均值 \(\mu_0\)；第二步从 \((h, \hat y_0)\) 细化 \(\mu_1\)。
- **合成变换（解码器）**：2 个 DCB 处理 \(\hat y\) 建模空间相关性；内容分支将 \(\hat y\) 上采样 4 倍到 1/4 分辨率渲染网格，生成 AdaLN 调制参数 \((\alpha,\beta,\gamma)\)，经残差逐点 MLP 后，每个网格向量投影为 4×4 RGB patch，再经 PixelShuffle 重组。

### 2.2 位精确线性 CDF 解码 + Meta Prior（第 3 节）

- **问题**：熵解码器内平台相关的浮点舍入误差会改变 CDF 表索引，导致后续所有 rANS 符号失同步。传统做法是整数化整个熵模型，但在超低复杂度预算下带来显著 CPU 开销与量化损失（全整数化在 CLIC 上 INT8 BD-rate 损失 5.7%，CPU 时间 85.9 ms）。
- **线性尺度解码器**：仅整数化独立的超尺度解码器，发现从 \(\hat z\) 到尺度的**简单线性投影**即可作为有效折中——INT8 下仅约 1.5% BD-rate 损失，CPU 时间从 28.1 ms 降到 1.2 ms。
- **线性 CDF 解码器（关键创新）**：直接预测 CDF 索引而非尺度。用线性投影得到共享的 M 行对数间隔高斯 CDF 表中的连续坐标：
  \[
  \tilde I_{CDF} = W\hat z + b_{QP},\quad I_{CDF} = \lfloor \text{clip}(\tilde I_{CDF}, 0, M-1) \rfloor
  \]
  训练时通过 \(\sigma(\tilde I_{CDF}) = \exp(\log\sigma_{\min} + \tilde I_{CDF}/M \cdot (\log\sigma_{\max}-\log\sigma_{\min}))\) 进行可微高斯似然评估，经验设置 \(\sigma_{\min}=0.11,\ \sigma_{\max}=256,\ M=64\)。推理时直接消费 \(I_{CDF}\)，消除运行时指数/对数运算，CPU 时间降至 1.6 ms，BD-rate 优于 INT8 超尺度解码器。
- **Meta Prior**：因线性 CDF 解码器极度简化，\(\hat z\) 承担更多码率建模责任（低内容复杂度图像中 \(\hat z\) 约占一半码流）。做法是：主模型训练完成后，仅将分解先验**后训练**为 \(N=64\) 个先验模型库，每个先验拟合不同内容复杂度区域的超潜向量；用 EM 过程联合优化先验与分配。推理时编码器对每个空间位置评估各先验编码代价并传输最佳 bank 索引（\(\log_2 N\) bit，由该位置所有通道共享）。在低复杂度图像上节省 9.8% 码率，整体节省 2.4%。
- **部署细节**：线性 CDF 激活与权重为 INT8，累加为 INT32，输出 UINT8 CDF 索引；Meta Prior bank 索引用定长编码，可进一步用合并编码优化。

### 2.3 启发式探针驱动的智能体进化（第 4 节）

- **四阶段循环**：**probe → analyze → reallocate → train**。分析变换固定，只进化神经接收器。
- **启发式探针**：
  - **冗余探针（PCA 维度）**：拟合数据集共享 PCA 基，找到使率失真损失增加不超过 \(\epsilon=1\%\) 的最小主成分维度 \(C^{PCA}_l\)；比值 \(C^{PCA}_l/C_l\) 越小说明通道冗余越可回收。
  - **余量探针（潜变量优化）**：冻结下游参数，逐图优化 \(a_l\)，测量 oracle PSNR 增益 \(G^{OPT}_l\)；增益大说明下游可从更具信息量的接口值中受益。
- **人–LLM 协作分析**：LLM 代理接收探针结果、网络图、参数共享、组件 MAC 开销与历史，提出固定预算的改动；人类研究者审核假设、实现可行性与预算核算，选出候选训练。双方均可引入 **spark**（新架构机制或可调因子），使优化空间本身随瓶颈发现而演化。
- **与 NAS 的区别**：启发式探针在从头训练前优先排序候选方向，而非枚举静态搜索空间；人–LLM 过程开放，探针证据可激发新参数/机制。
- **成果**：7 轮进化、22 次训练，E7 相对 E1 降低 10.2% BD-rate；随后调整通道为 16 的倍数得到 PULSE-S，再扩展得到 PULSE（5.2 kMAC/pixel）与 PULSE-L（20 kMAC/pixel）。

### 2.4 感知与 ROI 优化（第 5 节）

- **Stage I（LPIPS 优先预训练）**：显著提高 LPIPS 权重（\(\phi^I_{LPIPS}=1\)），建立细节合成能力。
- **Stage II（偏好优化）**：
  1. 降低 LPIPS 权重（\(\phi^{II}_{LPIPS}=0.25\)）以减少伪影；
  2. 引入基于 DINOv2 判别器的对抗训练（\(\phi_{GAN}=0.005\)）做分布级对齐；
  3. 引入 ROI 优化：预检测文本/人脸区域，在区域内加大 MSE/LPIPS 权重，并加入 FaceNet 与 CRNN-CNN 教师特征的语义对齐（\(\phi_{FaceNet}=1,\ \phi_{CRNN}=2\)）。
